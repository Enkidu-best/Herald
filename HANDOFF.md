# HANDOFF - Herald 3.0

Для того, кто продолжит работу. Что это, где что лежит, как проверить, что
решено и почему, что открыто.

## Что это

Локальная озвучка книг на Mac (Apple Silicon): книга -> части mp3/flac голосом
клонированного диктора. Всё офлайн. Окно - `tts_gui.py` (customtkinter, стиль
Scribe 2.3), ядро - `core/`, консоль - `cli.py`. Запуск: `Herald.app` или
`Запустить.command`. Окружение - только `.venv` проекта (torch 2.6; глобальный
torch 2.14 Scribe и Anonymizer не трогать).

## Где что

| файл | что |
|---|---|
| `tts_gui.py` | окно: Озвучка · Голоса · Настройки · Тема. Фоновые потоки окно не трогают - всё через очередь `App.ui()` |
| `theme.py`, `assets/icons/` | тема и иконки Lucide из Scribe 2.3 |
| `core/profiles.py` | движки: «Основной» (F5 Misha, 16 шагов EPSS) по умолчанию, «ESpeech», «Черновик» (7), «Silero» |
| `core/pipeline.py` | книга -> части: подготовка текста, нарезка, синтез, края кусков, продолжение (`.herald/`), запрет сна |
| `core/normalize.py` | числа и сокращения: сначала ru-normalizr, потом свой разбор как запасной |
| `core/stress.py` | ударения: RUAccent + омографы от silero-stress; `unify_book` - одно ударение на имя по книге; починка ONNX-входа RUAccent |
| `core/homograph_llm.py` | языковая модель (Ollama) как третий судья в омографах - **в программе не включена**, см. docs/Приёмка 3.0 |
| `core/engines/f5_mlx.py` | F5 на MLX; `variant="espeech"`; хвост куска по Silero VAD + затухание |
| `core/engines/f5.py` | подготовка образца голоса: отбор отрывка по тембру и **по тексту** (стихи, слова вне словаря, неуверенный Whisper - не берутся) |
| `core/engines/silero.py` | Silero v5_5_ru, готовые голоса |
| `core/vad.py`, `assets/models/silero_vad.onnx` | где кончается речь |
| `core/keepawake.py`, `core/log.py` | запрет сна; журнал `~/Library/Logs/Herald/herald.log` |
| `docs/` | задания, отчёты этапов, ключи слепых сравнений, снимки окна |
| `Инструменты разработки/` | тесты и стенды (ниже) |

Голоса: `~/.cache/text2audio/voices/` - `<имя>.wav` образец, `.txt` его
расшифровка, `.src.json` из какой записи сделан и кто читает, `.fx.json`
поправки звучания. Прежние образцы - в `запасные образцы/`.

## Как проверить после правок

```
.venv/bin/python "Инструменты разработки/test_gui.py"      # окно, 31 проверка, без синтеза
.venv/bin/python "Инструменты разработки/test_stress.py"   # ударения
.venv/bin/python "Инструменты разработки/test_synth.py"    # синтез обоих языков + гейт против чтеца
```
Стенды: `bench_stress.py` (расстановщики на Викисловаре), `bench_normalize.py`
(нормализаторы, 50 предложений), `bench_homograph_llm.py` (модель-судья),
`measure_edges.py` (края кусков, было -> стало), `voice_report.py` (звук против
записи чтеца), `snap_gui.py` (снимки окна в обеих темах).

## Решения и почему

- Голос выбирает Андрей **на слух, вслепую**; метрики только отсекают брак (числа
  трижды расходились с ухом). Ключи слепых наборов - в `docs/`.
- 16 шагов вместо 7: в слепом прослушивании 7 шагов - шум и металл. Цена - час
  звука около 2 ч 20 мин счёта; книгу ставят на ночь.
- Решения только общие: никаких словарей ударений и правил под конкретную книгу.
- Qwen3-TTS и Chatterbox в программу не вошли (монотонны в повествовании,
  ударения, 9,8 ГБ памяти / акцент). Их скрипты - в «Инструментах разработки»,
  окружение `.venv-candidates` - **удалить после того, как Андрей подтвердит
  выбор основного движка** (мини-набор в `Сравнение голосов 3.0 - глава/`).

## Открыто

- Окончательный выбор B16 или C16 - по мини-набору на настоящей главе.
- Женский голос: ждём запись от Андрея; правило отбора образца уже общее.
- Ударения рода (б): модель F5 иногда не слушается верного «+» в омографах
  (замОк, мУку, бЕлки, Атлас, Уже) - знак правильный, читается неверно.
  Общего лечения пока нет.
- `.venv-candidates` удалить после подтверждения выбора.
