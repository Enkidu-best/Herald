# HANDOFF - Herald 3.1

Для того, кто продолжит работу. Что это, где что лежит, как проверить, что
решено и почему, что открыто.

## Что это

Локальная озвучка книг на Mac (Apple Silicon): книга -> части mp3/flac голосом
клонированного диктора. Всё офлайн. Окно - `tts_gui.py` (customtkinter, стиль
Scribe 2.3), ядро - `core/`, консоль - `cli.py`. Запуск: `Herald.app` или
`Запустить.command`. Окружение - только `.venv` проекта (torch 2.6; глобальный
torch 2.14 Scribe и Anonymizer не трогать).

## Где что

| файл | что |
|---|---|
| `tts_gui.py` | окно: Озвучка · Голоса · Настройки · Тема. Фоновые потоки окно не трогают - всё через очередь `App.ui()` |
| `player.py` | мини-плеер готовой части (AVAudioPlayer через pyobjc): играть/пауза, стоп, перемотка, время |
| `theme.py`, `assets/icons/` | тема и иконки Lucide из Scribe 2.3 |
| `core/profiles.py` | движки: «Основной» B16 (F5 Misha, 16 шагов EPSS) по умолчанию, «ESpeech» C16 запасной, «Черновик» (7); Silero - выбором голоса |
| `core/pipeline.py` | книга -> части: подготовка текста, нарезка с отметками пауз, синтез пачками с упреждением, проверка краёв, паузы, кэш, продолжение (`.herald/`), запрет сна |
| `core/synthcache.py` | кэш синтеза: звук куска по хешу «текст + голос + движок», `~/.cache/text2audio/synth/` |
| `core/normalize.py` | числа и сокращения: сначала ru-normalizr, потом свой разбор как запасной |
| `core/stress.py` | ударения: RUAccent + омографы от silero-stress; `unify_book`; починка ONNX-входа RUAccent |
| `core/homograph_llm.py` | языковая модель (Ollama) как третий судья в омографах - **в программе не включена** |
| `core/engines/f5_mlx.py` | F5 на MLX: пачки (`synth_batch`), **якорь тишины в конце окна** (`TAIL_ANCHOR_SEC`), хвост куска по Silero VAD, исправленная маска внимания |
| `core/engines/f5.py` | отбор образца голоса: по тембру, по тексту, по звуку (обрезанный верх, срезанные вершины) - только при автоматическом отборе |
| `core/engines/silero.py` | Silero v5_5_ru, готовые голоса |
| `core/vad.py`, `assets/models/silero_vad.onnx` | где кончается речь |
| `core/keepawake.py`, `core/log.py` | запрет сна; журнал `~/Library/Logs/Herald/herald.log` |
| `docs/` | задания, отчёты этапов и приёмок, ключи слепых сравнений, снимки окна |
| `Инструменты разработки/` | тесты и стенды (ниже) |

Голоса: `~/.cache/text2audio/voices/` - `<имя>.wav` образец, `.txt` его
расшифровка, `.src.json` из какой записи сделан и кто читает, `.fx.json`
поправки звучания. Прежние и проигравшие образцы - в `запасные образцы/`.

## Как проверить после правок

```
.venv/bin/python "Инструменты разработки/test_gui.py"      # окно, без синтеза
.venv/bin/python "Инструменты разработки/test_pauses.py"   # паузы (--fast - без модели)
.venv/bin/python "Инструменты разработки/test_endings.py"  # окончания: три места + край окна
.venv/bin/python "Инструменты разработки/test_speed.py"    # пачка = по одному, кэш, профили
.venv/bin/python "Инструменты разработки/test_stress.py"   # ударения
.venv/bin/python "Инструменты разработки/test_synth.py"    # синтез обоих языков + гейт против чтеца
```
Стенды: `bench_endings.py` (окончания «было -> стало», в т.ч. на коде из
снимка через `--code-root`), `bench_speed.py` (RTF: пачки, упреждение, шаги,
образец), `bench_stress.py`, `bench_normalize.py`, `bench_homograph_llm.py`,
`measure_edges.py`, `voice_report.py`, `snap_gui.py` (снимки окна в обеих темах).

## Решения и почему

- Голос выбирает Андрей **на слух, вслепую**; метрики только отсекают брак (числа
  трижды расходились с ухом). Ключи слепых наборов - в `docs/`.
- Основной движок - **B16**, запасной - C16 (ESpeech, Apache-2.0). 32 шага в окно
  не выведены: в слепом сравнении хуже 16 и съедали окончания.
- Образец Вячеслава - прежний («К», стихи): на слух чище образцов из прозы.
- Съеденные окончания (3.1): F5 растягивает речь на всё окно, и последняя
  согласная упиралась в границу; запас длительности этого не лечит (замер: и
  при +40 % тишины после слова 6 мс). Лечение - известная тишина 0,3 с в конце
  окна; плюс сверка последнего слова по последним буквам.
- Квантование, float16 и два процесса **не помогают** (3.0) - повторно не мерить.
- Решения только общие: никаких словарей ударений и правил под конкретную книгу.

## Открыто

- Слепые наборы 3.1 ждут оценки Андрея (см. docs/Приёмка 3.1.md).
- Женский голос: ждём запись; правила отбора образца общие.
- Ударения рода (б): модель F5 иногда не слушается верного «+» в омографах.
- Пропуск слов в середине длинного смешанного куска (повествование + реплики):
  проверка краёв смотрит только первое и последнее слово.
