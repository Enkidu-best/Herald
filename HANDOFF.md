# HANDOFF - Herald 3.6

Для того, кто продолжит работу. Что это, где что лежит, как проверить, что
решено и почему, что открыто.

## Что это

Локальная озвучка книг на Mac (Apple Silicon), Windows и Linux: книга -> части
mp3/flac голосом клонированного диктора. Всё офлайн. Окно - `tts_gui.py` (customtkinter, стиль
Scribe 2.3), ядро - `core/`, консоль - `cli.py`. Запуск: `Herald.app` или
`Запустить.command`. Окружение - только `.venv` проекта (torch 2.6; глобальный
torch 2.14 Scribe и Anonymizer не трогать).

## Где что

| файл | что |
|---|---|
| `tts_gui.py` | окно: Озвучка · Голоса · Настройки · Тема. Фоновые потоки окно не трогают - всё через очередь `App.ui()` |
| `player.py` | мини-плеер: Mac - AVAudioPlayer (pyobjc), Windows/Linux - ffmpeg + sounddevice |
| `core/osutil.py` | всё, что различается по системам: пути, открыть/показать файл, ffmpeg из установщика, окна консоли, NVIDIA |
| вкладка «Прочитать вслух» | `tts_gui.py`, `_build_say_page` и `_say_*`: клавиши по коду и кириллическому имени (`SAY_CYR`, `SAY_CODES`), подсветка - `stream.chunk_spans` по числу букв |
| `core/stream.py` | звук по мере готовности (3.4): `Live` (расчёт старта по замеренной скорости, очередь, пауза, стоп), выходы (`SoundSink` - sounddevice, `ClockSink` - по часам для проверок, `CallbackSink` - сервис), `speak()` для любого текста |
| `core/speak_server.py` | сервис `/speak` для других программ: только 127.0.0.1, выключен по умолчанию, звук WAV потоком |
| `core/align.py` | проверка слов по звуку: выравнивание текста книги по звуку (wav2vec2 CTC), оценка каждого слова, `is_bad` |
| `core/asr.py` | распознавание: MLX Whisper на Mac, faster-whisper на Windows/Linux |
| `core/cuda_pack.py` | ускорение NVIDIA на Windows: докачка torch с CUDA (не проверено на видеокарте) |
| `core/engines/f5_torch.py`, `core/engines/f5net/` | F5 на torch (NVIDIA/процессор) - тот же алгоритм, что MLX; сеть DiT - копия из F5-TTS (MIT) |
| `packaging/`, `.github/workflows/` | установщик Windows (PyInstaller + Inno Setup) и проверки Linux/Windows на GitHub |
| `theme.py`, `assets/icons/` | тема и иконки Lucide из Scribe 2.3 |
| `core/profiles.py` | «Основной» (F5 Misha, 12 шагов EPSS) по умолчанию, «ESpeech» (12), «Черновик» (7); Silero - выбором голоса; множитель скорости по вычислителю |
| `core/pipeline.py` | книга -> части: подготовка текста, нарезка с отметками пауз, синтез пачками с упреждением, проверка краёв и слов по звуку, паузы, кэш, продолжение (`.herald/`), запрет сна |
| `core/synthcache.py` | кэш синтеза: звук куска по хешу «текст + голос + движок», `~/.cache/text2audio/synth/` |
| `core/normalize.py` | числа и сокращения: сначала ru-normalizr, потом свой разбор как запасной |
| `core/stress.py` | ударения: RUAccent + омографы от silero-stress; `unify_book`; починка ONNX-входа RUAccent |
| `core/homograph_llm.py` | языковая модель (Ollama) как третий судья в омографах - **в программе не включена** |
| `core/engines/f5_mlx.py` | F5 на MLX: пачки (`synth_batch`), **якорь тишины в конце окна** (`TAIL_ANCHOR_SEC`), хвост куска по Silero VAD, исправленная маска внимания |
| `core/engines/f5.py` | отбор образца голоса: по тембру, по тексту, по звуку (обрезанный верх, срезанные вершины) - только при автоматическом отборе |
| `core/engines/silero.py` | Silero v5_5_ru, готовые голоса |
| `core/vad.py`, `assets/models/silero_vad.onnx` | где кончается речь |
| `core/keepawake.py`, `core/log.py` | запрет сна; журнал `~/Library/Logs/Herald/herald.log` |
| `docs/` | задания, отчёты этапов и приёмок, ключи слепых сравнений, снимки окна |
| `Инструменты разработки/` | тесты и стенды (ниже) |

Голоса: `~/.cache/text2audio/voices/` - `<имя>.wav` образец, `.txt` его
расшифровка, `.src.json` из какой записи сделан и кто читает, `.fx.json`
поправки звучания. Прежние и проигравшие образцы - в `запасные образцы/`.

## Как проверить после правок

```
.venv/bin/python "Инструменты разработки/test_gui.py"      # окно, без синтеза
.venv/bin/python "Инструменты разработки/test_pauses.py"   # паузы (--fast - без модели)
.venv/bin/python "Инструменты разработки/test_endings.py"  # окончания: три места + край окна
.venv/bin/python "Инструменты разработки/test_speed.py"    # пачка = по одному, кэш, профили
.venv/bin/python "Инструменты разработки/test_words.py"    # сверка слов: по звуку и краёв
.venv/bin/python "Инструменты разработки/test_stream.py"   # звук потоком на заглушке: старт, стоп, файл = поток
.venv/bin/python "Инструменты разработки/test_torch_parity.py"  # torch = MLX (тот же шум - тот же мел)
.venv/bin/python "Инструменты разработки/test_player.py"   # плеер: оба способа
python "Инструменты разработки/smoke_pc.py"                 # Windows/Linux: Silero -> образец -> клон -> распознавание
.venv/bin/python "Инструменты разработки/test_stress.py"   # ударения
.venv/bin/python "Инструменты разработки/test_synth.py"    # синтез обоих языков + гейт против чтеца
```
Стенды: `bench_endings.py` (окончания «было -> стало», в т.ч. на коде из
снимка через `--code-root`), `bench_speed.py` (RTF: пачки, упреждение, шаги,
образец), `bench_stress.py`, `bench_normalize.py`, `bench_homograph_llm.py`,
`measure_edges.py`, `voice_report.py`, `snap_gui.py` (снимки окна в обеих темах),
`bench_words.py` (пропавшие слова было/стало), `bench_sound.py` (глава: время и
слова под подозрением по звуку), `eval_align*.py` (размеченный набор, порог),
`build_pair.py` (слепая пара), `bench_live.py` (время первого звука: Silero,
клон на фразе, пробник, /speak), `linux/Dockerfile` (Linux на Mac).

Тяжёлые шаги (синтез, распознавание, замеры, Docker) - только под общим
замком `../.heavy-lock` (параллельно работают Scribe и Legal Knowledge Desk).

## Решения и почему

- Голос выбирает Андрей **на слух, вслепую**; метрики только отсекают брак (числа
  трижды расходились с ухом). Ключи слепых наборов - в `docs/`.
- Основной движок - Misha accent_tune, с 3.2 на **12 шагах** (слепое сравнение
  15.10), запасной - ESpeech (Apache-2.0). 32 шага в окно не выведены.
- Образец Вячеслава - «К» (стихи); проза проиграла дважды, к ней не возвращаемся;
  образец не укорачивать (6,8 с - металл).
- Проверка слов **по звуку** (3.3, `core/align.py`): текст книги выравнивается
  по звуку wav2vec2 (bond005/wav2vec2-large-ru-golos) без языковой догадки -
  Whisper «дописывал» съеденные слова по смыслу. Пороги - по размеченному
  набору (`Инструменты разработки/разметка_3.3/набор.json`, ваши места 15.10):
  9 из 10 против 7 из 10 у строгой 3.2; ложных кусков 34 % (цель 5 % не
  достигнута, цена - время). Стойкий пропуск - чтение куска по предложениям.
  Включена по умолчанию, +17-19 % времени; только для клона F5 и русского.
  Выравнивание - на 2 потоках процессора, иначе тормозит синтез на видеоядре.
- Строгая проверка 3.2 (Whisper, текст против текста) из окна убрана, в коде
  осталась (`strict_words`) для замеров.
- Края кусков (3.5) - по звуку (`align.edges_ok`, `pipeline.EDGES_BY_SOUND`),
  когда включена проверка слов: Whisper на видеоядре делил его с F5 и на Mac
  тянулся ~8 с на кусок (замер `bench_profile.py`). Без проверки слов - Whisper,
  как раньше. Сверка на наборе окончаний: `eval_edges.py`.
- Режимы «Качество / скорость» (3.6, `profiles.QUALITY`, `engine_kwargs`):
  подсказка CFG на 4 / 6 (по умолчанию) / 12 шагах из 12 - `cfg_steps` движка
  (MLX и torch). Слепое 3.5: разница небольшая, Андрей выбрал скорость.
- Прогноз (3.6): `rtf_wall` с версией, режимом и голосом в ключе (`_rtf_key`);
  замеры прежних версий не берутся.
- Быстрые голоса Vosk / Piper (3.6, `core/engines/fast.py`): в программе только
  `ENABLED` - отмеченные Андреем в слепом наборе 3.6 (до оценки пусто). Piper -
  движок GPL-3: в установщик только с соблюдением GPL.
- Образец не укорачивать: 6,8 с - +35 % скорости, но металл (слепое 3.1).
- fp16/bf16 на M4 медленнее fp32 (3.0) - не мерить заново.
- Звук потоком (3.4): поток склеивается тем же кодом, что файл (`_Joiner`), -
  совпадает до сэмпла. Кусок играет, только когда посчитан целиком, поэтому
  запинка может выйти лишь на стыке. Старт: каждый следующий кусок должен
  досчитаться (+10 %) раньше, чем до него дойдёт игра; время счёта куска =
  a + b × звук (постоянная a - прогон образца F5), замеры в
  `~/.cache/text2audio/live_speed.json`. Полировка - ffmpeg на каждый кусок
  (разница с полировкой целого файла неслышима, замер в test_stream).
  Движок один на процесс: `stream.ENGINE_LOCK` (окно, сервис, книга).
- Куски F5 - 187 знаков (3.3; было 280): в длинных модель выкидывала фразы,
  счёт не дольше.
- Windows/Linux: тот же алгоритм на torch; мел - как у MLX (нули по краям,
  последний кадр отброшен), иначе звук расходился.
- Образец Вячеслава - прежний («К», стихи): на слух чище образцов из прозы.
- Съеденные окончания (3.1): F5 растягивает речь на всё окно, и последняя
  согласная упиралась в границу; запас длительности этого не лечит (замер: и
  при +40 % тишины после слова 6 мс). Лечение - известная тишина 0,3 с в конце
  окна; плюс сверка последнего слова по последним буквам.
- Квантование, float16 и два процесса **не помогают** (3.0) - повторно не мерить.
- Решения только общие: никаких словарей ударений и правил под конкретную книгу.
