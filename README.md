# Herald

**Книги, прочитанные вслух - голосом, который выберешь сам**

Локальная озвучка книг на Mac (Apple Silicon), Windows и Linux. Без интернета,
без подписок, без отправки данных. Голос клонируется из любой записи нужного
диктора.

</div>

---

## Возможности

- **Языки:** русский и английский. Язык книги определяется сам, под него берётся
  своя модель (для русского - с ударениями, для английского - без). Голоса
  помечены языком; для английской книги нужен образец англоязычного диктора.
  Язык образца определяется при его разборе автоматически.
- **Вход:** `.txt`, `.md`, `.docx`, `.epub`, `.fb2` (+`.fb2.zip`), `.pdf`
  (только текстовый слой; сканы пропускаются).
- **Главы:** из оглавления epub/fb2, стилей docx; иначе по «Глава N» или по размеру.
- **Ударения:** ставятся автоматически на весь текст: основа - RUAccent, в омографах
  (зАмок / замОк, стЕны / стенЫ, все / всё) - выбор silero-stress (схема выбрана замером
  на открытой разметке, см. docs/Отчёт этапа 1). Имя героя и другие слова вне словаря
  звучат одинаково во всей книге. Модель синтеза слушается знака «+» перед ударной гласной.
- **Числа и сокращения** - с верным падежом и родом (ru-normalizr): «везла 1250 руб.»
  -> «везла одну тысячу двести пятьдесят рублей», «в XXI веке» -> «в двадцать первом
  веке», «3,5 кг» -> «три целых пять десятых килограмма», «МГУ» -> «эм-гэ-у»,
  «А. П. Чехов» -> «А. Пэ. Чехов». Наш прежний разбор - запасной.
- **Голос:**
  - **клон по образцу** (F5): даёшь запись диктора - лучше его аудиокнигу, связную
    прозу; программа сама выбирает чистый отрывок 7-12 с. Стихи, перечисления,
    неуверенно распознанные куски, обрезанный верх и срезанные вершины волны в
    образец не берутся (только при автоматическом отборе - голос, выбранный на
    слух, не перепроверяется);
  - **готовые голоса Silero v5** (Айдар, Евгений, Бая, Ксения) - без клонирования,
    час звука за пару минут. **Лицензия Silero некоммерческая (CC BY-NC 4.0).**
- **Движки** (выбраны слепым прослушиванием, меняются в Настройках):
  «Основной» - F5 Misha24-10 accent_tune, 16 шагов (B16, по умолчанию);
  «ESpeech» - ESpeech-TTS-1 RL-V2 (C16, запасной), свободная лицензия
  Apache-2.0; «Черновик» - 7 шагов. Готовые голоса Silero включаются выбором
  голоса. Всё нативно на Apple Silicon через MLX.
- **Окончания слов** на концах кусков не теряются: в конец окна генерации модели
  задаётся тишина 0,3 с, и слово договаривается до неё (раньше в половине кусков
  последняя согласная упиралась в границу окна); последнее слово сверяется по
  последним буквам и при сбое переозвучивается с бо́льшим запасом.
- **Паузы** настраиваются: после предложения, после абзаца, между репликами
  диалога (0,4 / 0,8 / 1,1 с) - и между кусками, и внутри куска.
- **Пробник:** ~1 минута из середины главы - послушать голос до многочасовой начитки.
- **Выход:** файлы «Часть 1», «Часть 2»… по 10–60 минут звука или вся книга
  одним файлом; `.m4b` с главами-закладками - по желанию. Заголовок главы - в тегах.
- **Окно** в стиле Scribe / Legal Knowledge Desk, светлая и тёмная тема. Боковое
  меню: Озвучка · Голоса · Настройки · Тема. Карточка книги со «сколько звука /
  сколько ждать» ДО старта; этап словами («Шаг 2 из 3 · Озвучка - часть 4 из 27,
  15 % · осталось ~3 ч · RTF 1,9»); готовые части с мини-плеером (играть/пауза,
  стоп, время, перемотка) и «Показать в Finder»; голоса - кликабельные карточки
  с настройками звучания справа;
  «Пауза», «Остановить», «Продолжить озвучку» после остановки или сбоя; Mac не
  засыпает посреди книги. Технический журнал пишется в файл («Открыть журнал»
  в Настройках); «Подробности» на главной появляются только при ошибке или по
  настройке «Показывать технический журнал».

## Установка

### Windows

Установщик `Herald-Setup-3.5.exe` - на странице релизов GitHub. Внутри программа
и ffmpeg (LGPL); моделей и голосов внутри нет: модели (~4,5 ГБ) скачиваются при
первом запуске, голос вы добавляете сами («Голоса» → «Добавить образец…»).
Установщик не подписан: Windows покажет SmartScreen - «Подробнее» → «Выполнить
в любом случае».

Без видеокарты озвучка идёт на процессоре - это **сутки и больше на книгу**;
окно об этом предупреждает и предлагает готовые голоса Silero (быстрые и на
процессоре). Если есть видеокарта NVIDIA, в Настройках появится «Скачать
ускорение NVIDIA» (~2,5 ГБ, сборка torch с CUDA; **на настоящей видеокарте не
проверено**).

### Linux (из исходников)

```
sudo apt install python3-venv python3-tk ffmpeg libportaudio2
python3 -m venv .venv && source .venv/bin/activate
pip install torch==2.6.0 torchaudio==2.6.0 --index-url https://download.pytorch.org/whl/cpu
#   (видеокарта NVIDIA: --index-url https://download.pytorch.org/whl/cu124)
pip install -r requirements-pc.txt
python tts_gui.py
```

### Mac (Apple Silicon)

Ставим в **отдельное окружение (venv)**, чтобы не трогать глобальный torch 2.14
(им пользуются Scribe и Anonymizer). Нужен Python 3.12 и Homebrew-ffmpeg.

```
brew install ffmpeg
cd "…/Текст в Аудио"
bash setup_mac.command
```

Скрипт создаёт `.venv`, ставит проверенную связку (torch 2.6 + torchaudio 2.6,
F5, RUAccent и т. д.) и убирает лишний torchcodec. Модели (F5 accent_tune ~1.3 ГБ,
Silero ~40 МБ, распознавание образца) скачиваются при первом запуске и кэшируются.

Дальше каждый запуск - из этой папки, с активированным окружением:
```
source .venv/bin/activate
```

## Как запускать

**Обычный способ - двойной щелчок по `Herald.app`** в Finder.
(Запасной вариант - `Запустить.command`.)
Откроется окно. (Если macOS не даёт запустить в первый раз: правый клик по
файлу → «Открыть» → «Открыть».)

В окне (страница «Озвучка»):
1. Перетащи книгу в окно (или «Выбрать книгу»). Карточка книги сразу покажет:
   сколько частей, сколько будет звука и сколько ждать.
2. Справа - голос, длина частей и формат. Голоса добавляются и настраиваются на
   странице «Голоса» («Добавить образец…», «Звучание» - темп, высота, бас, яркость).
3. «Проверить голос (1 мин)» - минута из середины, чтобы не ждать часы зря.
   Звук начинается по мере готовности (с 3.4): окно пишет «Звук начнётся через
   ~N с», потом «Играет · считаю дальше»; в конце пробник ложится файлом рядом
   с книгой, как раньше.
4. «Озвучить книгу». Части появляются в списке слева по мере готовности - их
   можно слушать сразу. «Пауза» приостанавливает после текущего куска (Mac можно
   усыплять, «Продолжить» - сразу). «Остановить» прерывает, готовое остаётся, а
   кнопка превращается в «Продолжить (k из N)» - с того же места.
   При длине «Один файл (без частей)» части в конце склеиваются в один файл.

**Вкладка «Прочитать вслух»** (3.5, в левом меню): большое поле текста
(масштаб «A− 100% A+», Cmd/Ctrl + A, C, V, X, Z и при русской раскладке, меню
по правой кнопке), «Из буфера», «Открыть файл…» (txt, md, docx, fb2, epub, pdf -
тем же чтением, что книги), «Очистить». Голос в два шага: «Быстрый» (готовые
голоса Silero) или «Клон» - и конкретный голос из списка; выбор запоминается.
«Сразу» - звук после первой фразы, возможны паузы между предложениями; «Без
пауз» - старт по расчёту. ▶ / ❚❚ / ■, «Сохранить» (mp3), счётчик знаков и
прогноз: сколько звука и когда начнётся. Звучащее предложение подсвечено;
щелчок по предложению - читать с него. Справа - темп, высота, басы, яркость
для выбранного голоса («Сбросить», «Сохранить для голоса»); изменения
слышны с ближайшего куска, прогноз пересчитывается сразу. Английский текст
быстрым голосом не читается - готовых английских голосов нет, тогда читает клон.

### Звук по мере готовности (3.4)

Как у облачных сервисов: текст режется по предложениям, первый кусок короткий,
куски считаются по очереди и играют, пока считаются следующие. Клон F5 на Mac
считает медленнее реального времени (RTF 1,4-1,8), поэтому старт рассчитан:
играть начинаем, когда оставшийся счёт успеет до конца звучания (+10 %), по
скорости, замеренной на этом голосе и движке (запоминается в
`~/.cache/text2audio/live_speed.json`). Если машина всё же не успела - пауза
на стыке предложений, не посреди слова. Звук потока совпадает с итоговым
файлом до сэмпла. Это работает в пробнике, в «Прослушать» на странице
«Голоса», в «Послушать» у движков в Настройках и в «Прочитать вслух».

### Озвучка для других программ: `/speak`

Настройки → «Озвучка для других программ» → «Включить сервис /speak» (или
`python cli.py --serve`). По умолчанию выключен; слушает только `127.0.0.1`,
порт 8716 (меняется там же). Без интернета. Модели держатся загруженными, пока
сервис включён, и выгружаются после простоя (5-60 минут, настройка).

- `POST /speak` `{"text": "...", "fast": true, "voice": "aidar"}` - ответ:
  звук потоком, WAV (16 бит, моно, 48 кГц), кусок за куском. Начало ответа
  придержано по тому же расчёту, что в окне: если играть сразу, как приходит,
  звук не запнётся. `fast: false` - клон (`voice` - имя образца, иначе голос,
  выбранный в окне). `"play": true` - Herald играет сам, ответ сразу.
- `POST /stop` - остановить. `GET /health` - `{"ok": true, "version": "3.4"}`.
- Запросы из браузера - только со страниц `localhost`/`127.0.0.1`.

Python:
```python
import json, urllib.request, sounddevice as sd

req = urllib.request.Request("http://127.0.0.1:8716/speak",
                             data=json.dumps({"text": "Ход белых.", "fast": True}).encode(),
                             headers={"Content-Type": "application/json"})
with urllib.request.urlopen(req) as r, \
     sd.RawOutputStream(samplerate=48000, channels=1, dtype="int16") as out:
    r.read(44)                                   # заголовок WAV
    while chunk := r.read(9600):                 # 0,1 с звука
        out.write(chunk)
```

JavaScript (страница на localhost):
```js
async function speak(text) {
  const r = await fetch("http://127.0.0.1:8716/speak", {
    method: "POST", headers: {"Content-Type": "application/json"},
    body: JSON.stringify({text, fast: true})});
  const ctx = new AudioContext({sampleRate: 48000});
  const reader = r.body.getReader();
  let t = ctx.currentTime, head = 44, rest = new Uint8Array(0);
  for (;;) {
    const {value, done} = await reader.read();
    if (done) break;
    let b = new Uint8Array(rest.length + value.length);
    b.set(rest); b.set(value, rest.length);
    if (head) { const k = Math.min(head, b.length); b = b.subarray(k); head -= k; }
    const n = b.length >> 1;                     // целые сэмплы, остаток - в следующий раз
    rest = b.slice(n * 2);
    if (!n) continue;
    const pcm = new Int16Array(b.slice(0, n * 2).buffer);
    const buf = ctx.createBuffer(1, n, 48000);
    buf.getChannelData(0).set(Float32Array.from(pcm, x => x / 32768));
    const src = ctx.createBufferSource();
    src.buffer = buf; src.connect(ctx.destination);
    t = Math.max(t, ctx.currentTime); src.start(t); t += buf.duration;
  }
}
// стоп: fetch("http://127.0.0.1:8716/stop", {method: "POST"})
```

Из консоли: `curl -sN -X POST http://127.0.0.1:8716/speak -H 'Content-Type: application/json' -d '{"text":"Проверка связи."}' > звук.wav`.

### Из командной строки

```
source .venv/bin/activate
python cli.py "<твоя книга>.fb2" --voice "голос диктора"
```

Пробник на минуту (и заодно подготовка голоса из образца):
```
python cli.py "<твоя книга>.fb2" --ref "<аудиокнига диктора>.mp3" --preview 1 --chapter 2
```

Флаги: `--engine auto|f5mlx|f5torch|silero` (по умолчанию `auto`: Apple Silicon -
`f5mlx`, иначе `f5torch` на видеокарте NVIDIA или процессоре), `--engine-info`,
`--asr <файл>`, `--ref <образец>`,
`--voice <id>`, `--preview <мин>`, `--chapter <N>`, `--out <папка>`, `--m4b`,
`--no-mp3`, `--no-stress`, `--no-numbers`, `--nfe`, `--schedule epss|uniform`,
`--speed`, `--no-word-check`.

Прочитать вслух сразу (3.4): `python cli.py --speak "текст" --fast` (быстрый
голос) или `--speak - --voice "<образец>"` (текст из stdin, клон); `--save
файл.mp3` - ещё и сохранить. Сервис для других программ: `python cli.py --serve
[--port 8716] [--voice "<образец>"]`.

## Как устроено

```
core/
  readers.py    форматы -> Document (текст, метаданные, обложка)
  normalize.py  подготовка текста (числа, сокращения, чистка)
  stress.py     ударения (RUAccent + омографы от silero-stress), '+' перед ударной гласной
  chapters.py   разбивка на главы
  engines/      сменные движки за единым интерфейсом
    base.py       интерфейс TTSEngine
    f5_mlx.py     F5-TTS на MLX - основной: клон голоса, быстрее реального времени
    f5.py         F5-TTS на torch (cpu/mps) - эталон для сверки, медленный
    apple.py      системный голос macOS - мгновенно, но готовый голос, не клон
    silero.py     Silero - быстрый запасной, голос роботный
  assemble.py   сборка .m4b и mp3 через ffmpeg
  pipeline.py   convert_book() (вся книга) и preview_sample() (пробник)
cli.py          запуск без интерфейса
tts_gui.py      окно (customtkinter + перетаскивание файлов)
Запустить.command  двойной щелчок в Finder -> окно
```

Папки в проекте:
```
<диктор> Артем - ...   аудиокнига-образец, из неё сделан голос
Сравнение скорости/      mp3 одного текста в разных режимах - выбрать на слух
Сравнение голоса/        старый и новый образец голоса - сравнить
Инструменты разработки/  bench.py, verify.py, compare_speed.py, _selftest.py
Архив/                   прошлые замеры и пробники, для работы не нужны
```

В окне намеренно мало настроек: `--device mps`, число процессов и темп речи
убраны, потому что первые два проверены как бесполезные на этой машине
(см. «Скорость»), а темп - часть уже одобренного звучания голоса. Из CLI они
никуда не делись.

## Скорость (замеры на Apple M4, 16 ГБ)

RTF = секунды расчёта на секунду звука. RTF 0,62 - «час звука за 37 минут».
Разборчивость - доля слов, которые распознаются обратно из синтеза
(`verify.py`), замер на целой главе (219 слов).

| Движок (3.5, Apple M4) | RTF | Час звука за |
|---|---|---|
| **Основной, 12 шагов, проверка слов по звуку (по умолчанию)** | **~1,4** | ~1 ч 25 мин |
| Основной без проверки слов | ~1,4–1,5 | ~1 ч 25 мин |
| ESpeech (12 шагов), без проверки слов | ~1,4 | ~1 ч 25 мин |
| Черновик (7 шагов) | ~0,9 | ~55 мин |
| Готовые голоса Silero (не клон) | 0,03 | пара минут |
| Windows/Linux, процессор (раннер GitHub, 4 ядра) | ~15–22 | сутки |

Во время озвучки окно показывает настоящий, замеренный RTF и запоминает его
для следующего прогноза.

### 3.1: что ещё проверено (12 кусков главы, без переозвучек, Apple M4)

| что | RTF | итог |
|---|---|---|
| как в программе: по одному куску | 1,81 | исходная точка |
| упреждение (пока проверяются края куска N, считается N+1) | 1,80 | меньше 1 %, оставлено |
| пачка по 2 куска за проход | 1,97 | **медленнее**: видеоядро и так занято, добивка - лишний счёт |
| пачка по 3 | 2,04 | ещё медленнее |
| 12 шагов вместо 16 | 1,36 | −25 %, меняет звук - **слепое сравнение** у Андрея |
| образец 6,8 с вместо ~10 с | 1,18 | −35 %, может терять сходство - **слепое сравнение** |

Квантование 8/4 бита, float16/bf16 и два процесса проверены в 3.0 и не
помогают (ниже) - повторно не мерились. Кэш синтеза ускоряет не счёт, а
повторы: смена пауз или формата пересобирает книгу из готовых кусков.

**Откуда берётся время.** Профиль на книге: 76% - сам синтез, 11% - расстановка
ударений, остальное на проверку краёв. Главная статья расхода неустранима: на
каждый вызов модель заново прогоняет образец голоса (около 10 с) и только потом
саму речь, а полезен лишь второй кусок. Поэтому длина куска решает всё -
на 95 символах накладные съедают больше половины времени, на 280 около трети.
Отсюда и предел: быстрее реального времени на этом чипе получается только
ценой качества (меньше шагов, короче образец).

Итог: **в 7 раз быстрее исходного CPU-варианта и быстрее реального времени**.
Книга `<твоя книга>.fb2` (8,3 часа звука) - около 6,5 часов вместо 46.
Системным голосом macOS - 24 минуты, но это не клон.

### Откуда взялось ускорение

1. **MLX вместо torch** (в 4 раза). Тот же чекпойнт, та же математика - выход
   DiT совпадает с torch с точностью float32. Подробности поломок, которые
   пришлось починить, - в шапке `core/engines/f5_mlx.py`.
2. **EPSS - прорежённое расписание шагов** (ещё вдвое). Из работы
   [Fast F5-TTS, arXiv 2505.19931](https://arxiv.org/abs/2505.19931): у F5
   траектория ОДУ почти вся «решается» в начале, поэтому шаги надо густо ставить
   у t=0 и прореживать к t=1. Вместо 15 равномерных шагов - 7 неравномерных
   `[0, 2, 4, 6, 8, 16, 24, 32]/32` (потом sway sampling, как обычно).
   Это не переобучение и не другая модель, только другие моменты времени,
   поэтому голос тот же. Проверено: 94,1% против 94,5% - разница меньше слова.

**Что проверено и НЕ даёт выигрыша на этой машине:**

- **MPS (видеоядро через torch)** - не годится: на 16 ГБ упирается в память
  (OOM на длинных куска́х), а где не падает - в 10 раз медленнее MLX.
- **Квантизация весов (8 и 4 бита)** - 1,47 против 1,41: расчёт упирается не в
  память, а в арифметику (в отличие от языковых моделей), сжимать нечего.
- **float16 / bfloat16** - 1,50 / 1,52 против 1,40: на M4 fp32-матумножение уже
  идёт на полной скорости, а bf16 заметно теряет точность.
- **`--workers 2`** - 376 с против 372 с: видеоядро занято и одним процессом.
- **Куски длиннее 200 символов** - быстрее на 6%, но разборчивость падает до
  89,9% (модель обучена на отрезках до ~30 с, и мы подходим к границе).
- **Округление длины куска** (чтобы `mx.compile` не пересобирал граф) - накладные
  на перекомпиляцию оказались 0,03 с на кусок, то есть их нет.

Упор в железо: один вызов сети - 862 мс, это ~2,4 TFLOPS, около 56% от пика
fp32 у M4. 99,5% времени уходит в DiT; вокодер и подготовка текста - сотые доли.

Выбрать режим на слух:
```
python compare_speed.py            # разложит mp3 по папке «Сравнение скорости»
```

### Голос: как он делается и что на него влияет

Голос не выбирается из списка - он клонируется. Программе даётся любая запись
нужного диктора (подойдёт готовая аудиокнига), дальше она всё делает сама:

1. Слушает запись в нескольких местах по 25 секунд, пропуская начало
   (там обычно читают заголовок с паузами - для образца это плохой материал).
2. Расшифровывает каждый кусок через **Whisper large-v3-turbo на MLX** -
   быстро (секунды) и точно.
3. Выбирает отрывок 8–12 секунд с самой плотной беглой речью, режет его строго
   по границам фраз и запоминает вместе с расшифровкой.

**Чистота фона - важнее всего.** F5 клонирует не только тембр, но и акустику
образца: если в его паузах шумит, будет шуметь и книга. Замерено - переносится
один в один: образец 18,9 дБ → синтез 18,9 дБ (звук «металлический, как в
ведре»); образец 69 дБ → синтез 76 дБ (чисто). Поэтому отношение сигнал/шум -
первый критерий отбора, и только потом темп речи.

**Темп тоже задаётся образцом.** F5 считает длительность речи по соотношению
«байт текста на секунду образца». Первый образец был взят с начала главы, где диктор
медленно читает заголовок: 13,9 байт/с вместо обычных ~30. Модель решила, что
этот диктор говорит вдвое медленнее, и растягивала речь - это компенсировали
темпом 1.55, отчего голос звучал беднее оригинала. С нормальным образцом
(30,9 байт/с) темп 1.0 даёт на выходе 29,6 байт/с, то есть ровно как у живого
диктора. Сравнение - в папке «Сравнение голоса».

Ещё расшифровку раньше делала модель `small`, и она врала:
«раздерающимскрежитан» вместо «душераздирающим скрежетом». Неверный текст
образца портит клон, потому что модель сопоставляет звук с буквами.

### Формат записи

Выбирается в окне. Слушатель сравнил wav / mp3 320 / mp3 192 и разницы между
320 и 192 не услышал, поэтому 192 - база:

| формат | 8-часовая книга |
|---|---|
| **mp3 192 кбит/с (по умолчанию)** | ~660 МБ |
| mp3 320 кбит/с | ~1,1 ГБ |
| FLAC (без потерь) | ~1,4 ГБ |

На время счёта формат не влияет - кодирование занимает секунды.

### Настройки голоса

Кнопка **♪** рядом с выбором голоса открывает его настройки: **темп**,
**высота** (±4 полутона), **бас** и **яркость**, с прослушиванием на месте.
Всё это - свойства конкретного диктора, поэтому живут рядом с ним, а не в
общих настройках записи.

Тембр меняется постобработкой: фраза синтезируется один раз, дальше ползунки
правят только готовый звук, это сотые доли секунды. Темп работает иначе -
он задаётся при самом синтезе, поэтому при его смене фраза считается заново.

Что этим НЕ поправить: интонацию, манеру, паузы, акцент. Всё это модель
копирует из образца целиком. Если не нравится характер речи - нужен другой
образец, а не другие настройки.

Высота двигается приёмом `asetrate` + `atempo` (ускорить вместе с тоном, потом
вернуть темп). Фильтр `rubberband` сделал бы чище, но в Homebrew-сборке ffmpeg
его обычно нет, а на ±4 полутона разницы почти не слышно.

Настройки хранятся рядом с голосом файлом `<имя>.fx.json` и применяются при
каждой озвучке.

### Полировка звука

Перед кодированием каждый файл проходит цепочку фильтров ffmpeg
(`core/assemble.py: HD_FILTER`). Её подбирали не на слух вслепую, а по спектру
того варианта, который слушатель отобрал как лучший:

| полоса | «нравится» | получилось |
|---|---|---|
| 60–250 Гц (бас) | 12,8% | 11,9% |
| 2,5–6 кГц (согласные) | 20,4% | 23,1% |
| выше 6 кГц («воздух») | 11,6% | 13,8% |

**Важная поправка.** В заметках по демо-клипам цепочка начиналась с
`highpass=80` и `−2,5 дБ на 350 Гц`. На книге это роняло бас с 12,8% до 7,1%, и
голос становился тонким и плоским. Сейчас низ только чистится от инфранизкого
гула (50 Гц) и слегка поднимается на 110 Гц. `loudnorm` тоже убран: он ужимал
и без того сжатую динамику синтеза (12 дБ против 20 дБ у живого диктора).

**Громкость подбирается по факту, а не прибавляется наугад.** Сначала мерится
настоящий пик готового звука, потом он приводится к 0,88 обычным умножением.
Фиксированная прибавка с лимитером (так было) давала треск: эквалайзер и сам
поднимает бас с верхом, сигнал упирался в максимум, и лимитер работал
непрерывно. Замеры резких скачков волны на 25 секундах: +4 дБ с лимитером -
13003, нормализация по пику - 142, столько же, сколько в одобренном варианте.

Настоящих верхних частот это не создаёт: F5 отдаёт 24 кГц, реальный спектр - до
~12 кГц. Для честного «HD» нужен нейросетевой апскейл (AudioSR), пока не встроен.

### Если клон не нужен, а нужно быстро

Движок «Голос macOS» использует системный синтез (`say`): **RTF ≈ 0,05**, час
звука за пару минут, никаких моделей вообще. Это готовый голос, не клон, и
звучит он заметно проще. Ударения ему не передаются - у него свой словарь.

Больше русских голосов Apple можно доустановить: Системные настройки →
Универсальный доступ → Устная речь → Системный голос → Управление голосами →
Русский. Из коробки стоит только базовый compact «Milena».

**Personal Voice (клон голоса от Apple) для этой задачи не подходит:** он
создаётся только живой записью 150 фраз тем человеком, чей голос клонируется,
прямо на устройстве. Подсунуть ему mp3 чужого диктора нельзя - ни через
интерфейс, ни через API.

python "Инструменты разработки/test_synth.py"   # главное: текст доходит до звука

обработчики и ловит исключения из колбэков tkinter - они иначе просто
печатаются в консоль и никого не останавливают.

## Инструменты разработки

- `bench.py` - замер RTF одного варианта (`--engine`, `--device`, `--nfe`,
  `--dtype`, `--quant`, `--chars`, `--total-sec`).
- `verify.py` - распознаёт готовый wav и считает долю совпавших слов. Нужен
  потому, что «речеподобная каша» по длительности и громкости выглядит как
  нормальная речь, и на слух каждый вариант не переслушать.
- `compare_speed.py` - mp3 одного текста при разных `nfe` для выбора на слух.
- `_selftest.py` - чтение форматов и нормализация текста.
- `test_synth.py` - сквозная проверка озвучки на двух языках.
- `test_gui.py` - прогон окна без человека.
- `bench_endings.py` - окончания «было -> стало» на 33 фразах (`окончания_33.json`),
  `--code-root` - запустить на коде из снимка прежней версии.
- `bench_speed.py` - RTF конвейера: пачки, упреждение, шаги, образец.
- `eval_align.py`, `eval_align_skeleton.py`, `eval_align_threshold.py` - оценки
  слов по звуку на размеченном наборе (`разметка_3.3/набор.json`) и подбор порога.
- `bench_sound.py` - глава: время и слова под подозрением (`--check`,
  `--max-chars`, `--seed`); `build_pair.py` - слепая пара для прослушивания.
- `bench_live.py` - время первого звука: Silero, клон на фразе, пробник, `/speak`;
  `eval_tail.py` - растянутые гласные и ударение по звуку на готовой главе.

  главы - в тегах. Из названия книги убираются пометки вроде «[litres]».
- Длина файла 60 минут и режим «Один файл (без частей)»: синтез идёт частями
  (слушать можно сразу, «Стоп» ничего не теряет), в конце - склейка в один файл.
- Кнопка «Пауза / Продолжить».
- Образец голоса отбирается по тембру всей записи, а не только по чистоте фона;
  результат сверяется с записью именно этого чтеца (см. ЭТАЛОННЫЕ_НАСТРОЙКИ).

**2.0** - MLX-движок, английский язык, клонирование голоса по образцу, новое окно.
