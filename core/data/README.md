# Данные программы

`stress_wiktionary.tsv.gz` - ударения 862 тыс. словоформ русского языка с грамматикой
формы (падеж, число). Источник - Викисловарь (Wiktionary), лицензия
[CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/); выгрузка - пакет
[tsnorm 1.1.2](https://github.com/NetherQuartz/TextForSpeechNormalizer) (Vladimir Lar'kin, MIT),
переложена в текст без изменений содержания (`Инструменты разработки/wikt_to_tsv.py`).
Файл распространяется на условиях CC BY-SA 3.0, отдельно от кода программы (MIT).

Строка: `ключ (без ударения, е вместо ё)` - `форма с «+» перед ударной гласной` - `теги`
(им, род, дат, вин, тв, пр, мест - падеж; ед, мн - число; осн - основная форма статьи).

`stress_zaliznyak.tsv.gz` - ударения 108 тыс. словоформ по «Грамматическому словарю
русского языка» А. А. Зализняка (1977): набор Schriner (2022), DataverseNO,
[doi:10.18710/AAFCJP](https://doi.org/10.18710/AAFCJP), лицензия CC0 1.0 (общественное
достояние). Строка: `форма (е вместо ё)` - `номер ударной гласной` (варианты через
запятую). Собран `Инструменты разработки/zaliznyak_to_tsv.py`. Это выборка форм, не
полные парадигмы: при споре разметчиков он решает первым, Викисловарь - вторым.
