# Голос по языку отрывка - общий модуль `tts_client`

Версия 1.0.0 · 24.10.2026 · пункт 2а ночи 23-24.10. Стандарт: «Единый стандарт программ», 2.6 и раздел 7 (строка «Голос (TTS)»). Пара к модулю [`lang`](../lang/README.md).

## 1. Зачем

Английский голос Piper (espeak-ng) не знает кириллицы и читает её по символам; русский Silero так же коверкает латиницу. В репетиции на английском русская фраза модели прозвучала по буквам. Правило: **голосу никогда не уходит текст чужого алфавита** - текст делится на отрывки по языку, каждый отрывок читает голос своего языка.

## 2. Практика

- Многоязычный синтез в промышленных системах (SSML `<lang xml:lang="…">`, Azure / Google TTS) - смена голоса или языка на отрывке, а не один голос на всю фразу.
- Для пары «русский / английский» язык отрывка надёжно определяется по алфавиту слова (кириллица / латиница); цифры и знаки идут с соседним словом.

## 3. Правила

3.1. **Отрывок** - подряд идущие слова одного алфавита (кириллица - `ru`, латиница - `en`) вместе со знаками, цифрами и пробелами между ними. Знаки и цифры в начале текста - с первым словом.
3.2. Каждый отрывок - голосу его языка (`voice_for(lang)`): основной голос сессии, если язык совпадает, иначе - голос по умолчанию для этого языка. Нет голоса для языка - отрывок не звучит (в журнал: `skipped`), по буквам не читается.
3.3. Текст отрывка содержит буквы только своего алфавита - это проверяется перед синтезом (`assert_clean`).

## 4. API

```python
from common.tts_client import split as ts
ts.segments("Answer: используйте STAR", "en")
# [("en", "Answer:"), ("ru", "используйте"), ("en", "STAR")]
for sr, pcm in ts.speak(text, "en", voice_for=lambda lang: VOICES.get(lang), synth=my_synth, skipped=log):
    ...
```

## 5. Проверки

`tests/test_split.py`: «Answer: используйте STAR» - русское слово уходит русскому голосу, ни одной кириллической буквы английскому; русская фраза с SLA; цифры и кавычки; нет голоса для языка - отрывок пропущен, не прочитан по буквам.
