# llm_config - одна настройка модели Ollama для всех программ

Версия 1.0.0 · 11.11.2026 · задание «_Общая база 01». Стандарт, раздел 7.

## Зачем

Модель Ollama по умолчанию была прописана в каждой программе отдельно - смена модели означала правку кода во всех
программах. Теперь значения по умолчанию берутся из одного файла `Разработка ПО/.models.json` (вне git).

## Как работает

`model(role="main", env=..., user=...)` и `ollama_url(env=...)` берут первое непустое значение:

| № | Откуда | Пример |
|---|---|---|
| 1 | переменная окружения программы (`env=` - имя или список имён) | `IC_LLM_MODEL`, `CLEARDOC_LLM_MODEL`, `TRIAGE_MODEL` |
| 2 | выбор пользователя в Настройках программы (`user=`) | «Модель интервьюера» в Interview Coach |
| 3 | `.models.json` - ищется вверх от папки копии модуля (`<проект>/common/llm_config` → `Разработка ПО/`) | `{"main": "qwen3.5:9b"}` |
| 4 | встроенное значение (`DEFAULTS`, `DEFAULT_URL`) | без файла: GitHub, CI, сборка Windows |

Роли: `main` - рабочая модель (qwen3.5:9b), `fallback` - запасная (qwen3.5:4b), `embed` - эмбеддинги (bge-m3),
`ollama_url` - адрес Ollama (http://127.0.0.1:11434). Новую роль можно дописать в файл без правки модуля
(`model("vision")`), но тогда программа без файла получит `KeyError` - передавайте `default=`.

Файл:

```json
{"main": "qwen3.5:9b", "fallback": "qwen3.5:4b", "embed": "bge-m3", "ollama_url": "http://127.0.0.1:11434"}
```

- Файл читается при каждом вызове (он маленький). Программы, которые берут значение при старте (константа в
  `config.py`), увидят новое значение после перезапуска.
- Файла нет - встроенные значения, молча. Файл битый (не JSON, не объект) - встроенные значения и одно предупреждение
  в журнал (`logging`). Значение не строка или пустое - как нет.
- `LLM_MODELS_FILE=<путь>` - явный файл (тесты, особый запуск); `LLM_MODELS_FILE=` (пусто) - файл не читать.
- `python -m common.llm_config` (из папки проекта) - какие значения видит программа и откуда.

## Практика (шаг 1а)

Слои «переменная окружения → файл настроек → встроенное значение» - общий приём локальных LLM-программ (llama-rs, oLLM,
gptme, LocalAI); поиск файла вверх по папкам - как `pyproject.toml` у ruff / black и `.aider.conf.yml` у aider; роли
вместо имён моделей - как псевдонимы моделей (model aliases) в aider и LiteLLM. Своя библиотека не нужна: ~100 строк
без зависимостей.

## Как подключить

1. Копия: `_общие модули/scripts/sync_common.sh llm_config <проект>` → `<проект>/common/llm_config/`.
2. В коде заменить только значение по умолчанию, логику выбора не трогать:

```python
from common.llm_config import llm_config as lc
LLM_MODEL = lc.model("main", env="IC_LLM_MODEL")          # было os.environ.get("IC_LLM_MODEL", "qwen3.5:9b")
OLLAMA_URL = lc.ollama_url(env="OLLAMA_URL")              # было os.environ.get("OLLAMA_URL", "http://localhost:11434")
```

## Проверка модуля

`python3 -m unittest discover -s "_общие модули/llm_config/tests"` - 4 уровня приоритета, файла нет, файл битый,
ближайший файл, явный путь, смена значения в файле без перезапуска.
