## 2. Съеденные окончания и щелчки в конце фразы

Общая проблема F5: модель недооценивает длительность и обрезает последнее слово, а склейка оставляет щелчок. Решение общее, без правил под слова:
- каждый кусок заканчивается знаком препинания (если нет - ставить точку);
- небольшой запас длительности (подобрать: ориентир +5-8 %) с последующей обрезкой тишины на конце по Silero VAD, а не по порогу громкости;
- плавное затухание 10-30 мс на концах кусков перед склейкой;
- существующая проверка краёв (`_edges_ok`) должна ловить недоговорённое последнее слово: сравнивать последнее слово по ASR с текстом и пересинтезировать.

Проверка: 30 фраз + повествование + диалог. Число фраз с неполным последним словом по ASR и число резких скачков в последних 100 мс - «было → стало» для B16 и C16.

## 3. Подготовка текста: числа, сокращения, инициалы

Ошибки из «Сложного текста», одинаковые у всех моделей:
- «три целых пять десятых кг» → нужно «три целых пять десятых килограмма»;
- «1 250 руб.» → «одна тысяча двести пятьдесят рублей» при «везла одну тысячу…» (падеж);
- «XXI веке» → «двадцать первый веке» (падеж);
- «МГУ» звучит неверно у F5 (Qwen читает верно);
- инициалы «А. П. Чехов» - невнятно, нужно «А. П.» буквами.

Сделать (общие правила, без словарей под текст):
1. **Аббревиатуры из заглавных букв** (2-5 букв, не слово целиком) - читать по буквам: «МГУ» → «эм-гэ-у», «ООН» → «о-о-эн». Исключения - только те, что обычно читаются словом (ВУЗ, МИД, ГОСТ): их определять по общему правилу (есть гласные и читается как слог) или по открытому списку, а не по ручному.
2. **Инициалы** («А. П.», «Л.В.») перед фамилией - читать названия букв: «А. Пэ. Чехов», «Эл. Вэ.».
3. **Числа с согласованием падежа и рода** (римские века, суммы, дроби с единицами). Сначала проверить готовые нормализаторы для русского TTS - например RUNorm (тот же автор, что RUAccent) или другие открытые; сравнить с нашим `normalize.py` на наборе из ~50 предложений (числа в падежах, даты, века, проценты, единицы, дроби, суммы). Взять лучший по замеру, наш - как запасной.

Не тратить больше 1-2 дней: такие места в книгах встречаются, но не на каждой странице.

## 4. Ударения в омографах

Ошибки в «30 фразах» одинаковые у всех F5-моделей - значит, неверен сам знак «+», а не модель:
- «все д+ороги ведут к морю» (нужно дор+оги);
- «эти сл+ова запомнились» (нужно слов+а);
- «эта дорога ужЕ прежней» (нужно +уже, «уже» - сравнительная степень);
- «ключ легко открыл з+амок» (нужно зам+ок);
- «терпела страшную мук+у» (нужно м+уку);
- «рыжие белк+и» (нужно б+елки);
- «географический атл+ас» (нужно +атлас);
- «не сказал ни слов+а» (нужно сл+ова).

Для справки (не ошибки): «пакет мук+и» - верно (мука-продукт); «письма нам очень дорог+и» - допустимый вариант.

Предложение: **локальная языковая модель как третий судья только для омографов.** Слово-омограф + предложение целиком → Ollama (qwen3.5:9b, при нехватке памяти 4b) выбирает вариант ударения из заданных расстановщиком. Это общий способ: модель понимает смысл фразы, словарей не нужно.

Проверить на 9 141 предложении из Викисловаря (омографы) и 30 фразах: RUAccent + silero (сейчас) против «+ языковая модель». Брать, только если лучше, и учесть время на книгу (омографов на странице немного). Модель выгружать из памяти перед синтезом.
