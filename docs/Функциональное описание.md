## 1. Коротко

Herald - программа для Mac (код работает и на Windows / Linux), которая превращает книгу (txt, md, docx, epub, fb2, pdf с текстом, zip с fb2) в аудиокнигу: части mp3 или FLAC в папке рядом с книгой. Читает голос-клон (сделан из записи чтеца) или готовый быстрый голос. Перед озвучкой текст готовится сам: числа, даты и сокращения - словами, ударения - автоматически. Озвучка книги идёт часами; части появляются по мере готовности и сразу слушаются во встроенном мини-плеере. Ещё программа читает вслух любой вставленный текст и даёт голос другим программам Андрея через локальный сервис `/speak`.

Для кого и главные сценарии UC-01…UC-07 - в `Продукт.md`. Ограничение: голоса настоящих чтецов (Ященко, Герасимов) и голоса «Диктор 1-3» / «Голос 01-04» - только для личного использования; основной движок F5 (Misha24-10) и голоса Silero - некоммерческие лицензии.

Версия в окне - **3.8** (`core/__init__.py:5`).
⚠ разрыв: версия задана в коде вручную и не поднималась после выпуска 3.8 - с тех пор 15 коммитов (11а, 11б: Qwen-голоса, свои веса F5, шумоподавление), а окно и `/health` по-прежнему показывают 3.8; стандарт интерфейса (п. 1) требует версию из пакета, «не вручную». `core/__init__.py:5`, `git log v3.8..HEAD`.

## 2. Карта экранов

Одно главное окно: слева меню, справа рабочая область со своей верхней строкой. Экраны (страницы) строятся при запуске и переключаются пунктами меню; переходов «вглубь» нет, поэтому кнопки «← Назад» нет.

```
Меню слева                       Рабочая область
─────────────                    ────────────────────────────────────────────
Озвучка ───────────────────────► 3.2 «Озвучка» ──(«Как будет прочитано»)──► 3.2a окно «Как будет прочитано»
Прочитать вслух ───────────────► 3.4 «Прочитать вслух»
Голоса ────────────────────────► 3.5 «Голоса» ──(«✎», «⋯ › Переименовать…»)──► окно «Имя голоса»
                                              ──(«Добавить образец…»)──► выбор файла ► окно «Имя голоса» (ввод)
──────────
Справка ───────────────────────► 3.7 «Справка»
Настройки ─────────────────────► 3.6 «Настройки»
Тема: … (по кругу: Системная → Светлая → Тёмная)
Herald 3.8 / локально на этом Mac

Верхняя строка: «Раздел › Книга» · статус видеокарты · RU | EN · «Aa» ──► панель «Размер текста» под кнопкой (не окно)
Меню macOS «Правка»: Скопировать · Выделить всё · Скопировать подробности
```

Входы без окна: 3.8 сервис `/speak` (для других программ), 3.9 консоль `cli.py`.

Переходы внутри: щелчок по голосу на «Голосах» выбирает его и для «Озвучки» (3.5.6); «Звучание голоса ›» на «Озвучке» и «Прочитать вслух» открывает «Голоса» с этим голосом справа (3.2.4а, 3.4.11); «Скачать» быстрый голос со страницы «Прочитать вслух» запускает загрузку, ход которой виден там же и на «Голосах» (3.4.6); смена языка или сворачивание меню пересобирают окно, книга и раздел остаются (3.1.3, 3.1.6).

### 3.2 «Озвучка»

- **Назначение:** превратить книгу в аудиокнигу (UC-01, UC-02, UC-03, UC-05).
- **Как попасть / как уйти:** пункт меню «Озвучка» (открывается при запуске); уход - любой другой пункт, книга остаётся выбранной. Новый запуск программы - пустая карточка (стандарт 3.4); прошлые книги - в «Недавних».

### 3.2a Окно «Как будет прочитано»

- **Назначение:** увидеть до многочасовой озвучки, как текст книги уйдёт в модель: числа и сокращения словами, ударение - знаком над гласной (UC-03), - и **поправить ударение в спорном слове этой книги**, пока не поздно. Зачем, если текст не правится: видно, где программа сомневается (числа, имена, омографы), и проблему можно снять до озвучки, а не услышать через 8 часов.
- **Решение (задание 12, п. 5):** просмотр остаётся; у подсвеченного **спорного** слова (два расстановщика ударений разошлись) - щелчок «ударение на …» с вариантами. Поправка действует **только на эту книгу** и применяется при следующей озвучке (и пробнике). Это не ручной словарь ударений (его Андрей отверг): нельзя завести своё слово, правятся только слова, которые программа сама отметила спорными, и только в этой книге.
- **Как попасть / как уйти:** кнопка 3.2.9; закрыть - Esc или крестик окна.
- **Что видно:** строка «Так текст уйдёт в модель: числа словами, ударение - знак над гласной. Подсвечены спорные слова (N): щелчок - выбрать ударение для этой книги.»; текст по частям «=== Часть N. Заголовок ===» (деление - по выбранной «Длине частей»); спорные слова подсвечены жёлтым, поправленные - зелёным.
- **Элементы и действия:**

| № | элемент | что делает | что меняется на экране / в данных | когда неактивен и почему |
|---|---|---|---|---|
| 3.2a.1 | текст | читать и копировать (Cmd+C, меню правой кнопки) | - | правка текста недоступна: «Только просмотр: так текст уйдёт в модель» |
| 3.2a.2 | щелчок по подсвеченному слову | меню: «Ударение: за́мок», «Ударение: замо́к» (по одной строке на каждую гласную слова) и «Как предложила программа» | все такие слова книги в окне показаны с выбранным ударением и подсвечены зелёным; поправка записана в `~/.cache/text2audio/book_fixes.json` (по пути книги) | у неподсвеченных слов меню нет |
| 3.2a.3 | строка «Поправлено слов: k · применится при следующей озвучке» | что уже выбрано | - | видна, когда есть поправки |

- **Данные:** если книга уже озвучивалась и «текст с ударениями.txt» новее книги и поправок - показывается он; иначе текст готовится заново (минуты на большую книгу) и сохраняется вместе со списком спорных слов в `_служебное/`. Поправки (`book_fixes.json`) лежат вне папки книги и не удаляются вместе со служебными файлами. В озвучке поправка ставится после всех шагов ударений (RUAccent, silero-stress, справочник, единое ударение по книге) - на каждое вхождение слова в книге; кусок с поправленным словом пересчитывается, остальные берутся из кэша. «Продолжить» после поправки заново собирает только части, где это слово есть (в них считаются только куски с ним), остальные готовые части не трогает.
- **Состояния:** подготовка - кнопка «Готовлю текст…»; спорных слов нет - строка без второй половины; ошибка - окно «Ошибка» с текстом.
- **Ограничения:** ударения - только для русского текста; поправка - только знаком «+» модели (F5 и Qwen ru-stress); готовые голоса Silero / Vosk / Piper ставят ударения сами.
- **Сценарии проверки:** UC-03: книга с числами и омографами → «Как будет прочитано» → числа словами, ударения знаком над гласной, спорные слова подсвечены → щелчок по «замок» → «Ударение: замо́к» → все «замок» книги зелёные с ударением на «о» → закрыть, открыть снова → поправка на месте → пробник читает «замо́к».

## 6. Чего нет и почему

- **Ручного словаря ударений нет** - решение Андрея (17.10, подтверждено в 11а): своё слово завести нельзя, ударения ставятся автоматически. Поправка в «Как будет прочитано» (3.2a) - не словарь: только для слов, которые программа сама отметила спорными, и только в этой книге.
- **Правки текста книги в окне нет** - текст берётся из файла как есть.
- **Распознавания сканов (OCR) нет** - PDF без текстового слоя пропускается с сообщением.
- **Очереди книг и одновременной озвучки нет** - движок один на процесс.
- **Выбора «чем считать» нет** - программа решает сама (MLX / NVIDIA / процессор).
