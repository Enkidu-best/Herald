# Чек-лист: Herald 3.2 на настоящей Windows

На раннерах GitHub проверено без экрана: установка → пробник (Silero и клон F5
на процессоре) → удаление. Окно, звук и видеокарту там проверить нельзя - это
по списку ниже. Отметьте, что получилось, и пришлите журнал, если что-то нет
(«Настройки» → «Журнал проблем»).

## Установка
- [ ] `Herald-Setup-3.2.exe` запускается (SmartScreen: «Подробнее» → «Выполнить
      в любом случае»), ставится без прав администратора.
- [ ] В меню «Пуск» есть Herald; программа открывается, окно без чёрной консоли.
- [ ] Шрифт - Segoe UI, светлая и тёмная тема переключаются.

## Голос
- [ ] «Голоса» → «Добавить образец…» → запись диктора (mp3). Первый раз
      скачиваются модели (~3 ГБ) - видно, что идёт работа; голос появляется.
- [ ] Щелчок по карточке голоса выбирает его, справа - темп, высота, бас,
      яркость; «Прослушать» играет фразу (звук из колонок).

## Озвучка
- [ ] Под «Движок» написано, чем считается: «процессор - очень медленно» и
      совет про Silero (или «видеокарта NVIDIA» после докачки).
- [ ] «Проверить голос (1 мин)» - пробник появляется в списке частей.
- [ ] Мини-плеер у части: играть/пауза, стоп, ползунок, время. Другая часть
      останавливает первую. Закрытие окна останавливает звук.
- [ ] Кнопка «В папке» открывает Проводник с выделенным файлом.
- [ ] Во время озвучки компьютер не уходит в сон (оставьте на 30+ мин при
      коротком таймере сна); на «Паузе» - уходит.
- [ ] Готовый голос Silero (Айдар, Ксения…) озвучивает быстро.

## Видеокарта NVIDIA (если есть)
- [ ] В Настройках есть «Скачать ускорение NVIDIA»; скачивается ~2,5 ГБ.
- [ ] После перезапуска под «Движок» - «видеокарта NVIDIA»; пробник заметно
      быстрее, чем на процессоре; звук такой же.

## Удаление
- [ ] «Удалить Herald» из меню «Пуск» убирает программу. Голоса и модели
      остаются в `%USERPROFILE%\.cache` - их можно удалить вручную.
