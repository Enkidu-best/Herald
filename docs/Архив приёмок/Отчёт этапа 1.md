# Отчёт этапа 1 - Herald 3.0

Этап 1 по заданию «01. Задание для Claude Code - Herald 3.0»: ударения (раздел 1),
слепое сравнение голосов (раздел 2), исправления кода (раздел 3). Основной движок
не менялся, окно не переделывалось - это этап 2, после прослушивания.

## Коротко

1. **Главная причина ошибок ударений найдена, и это не расстановщик.** RUAccent
   месяцами падал на каждом слове вне словаря (имена, выдуманные слова), а
   программа глотала ошибку и отдавала фразу в синтез **совсем без ударений**.
   На «Жажде власти» так ушли **19 % фраз (25 % слов)** - вся книга озвучена с
   этим сбоем. Исправлено. Подробности - в 1.1.
2. **Ударения теперь ставятся по схеме «RUAccent + омографы от silero-stress»**,
   выбранной замером на открытой разметке: в омографах 91,9 % против 90,1 % у
   одного RUAccent, в обычных словах RUAccent точнее (99,4 % против 99,2 %).
3. **Слово вне словаря звучит одинаково во всей книге** (было: «ланд-капитан» -
   18 раз «лАнд-», 11 раз «-капитАн»).
4. Слепой набор готов: `Сравнение голосов 3.0/`, лист `Оценка.md`.
   Восемь вариантов (шесть кандидатов задания плюс B и C на 16 шагах) прошли отсев без явного брака; ключ «буква -> модель» - в `docs/ключ сравнения (не открывать до оценки).md`.
5. Раздел 3: Mac больше не засыпает посреди книги; после сбоя или «Стопа» книга
   продолжается с того места; временные гигабайты больше не копятся; ошибки
   пишутся в журнал и показываются в окне; лицензии - в README; тире - короткие.

## 1. Ударения

### 1.1. Где возникает ошибка: (а) неверный «+» или (б) модель не послушалась

**Найденный сбой (а).** С transformers 5.x токенизатор RUAccent перестал
отдавать вход `token_type_ids`, без которого падает его модель ударений для
слов вне словаря. `add_stress` ловил исключение и возвращал фразу как есть, без
единого «+». Пакеты стоят в `.venv` с 26.09, книга озвучена 29.09 - сбой
действовал на всю книгу.

Замер на всей «Жажде власти» (22 части по 45 мин, старое поведение воспроизведено):

| | всего | ушло БЕЗ ударений |
|---|---|---|
| фраз | 8 218 | **1 564 (19,0 %)** |
| слов | 99 124 | **25 032 (25,3 %)** |

Исправление - в `core/stress.py` (`_patch_onnx_inputs`): недостающий вход
дополняется нулями, как это было до обновления пакетов; сам пакет не правится.
После исправления на всей книге без единого ударения остаются 15 фраз - это
короткие реплики из односложных слов. Плюс тест `Инструменты разработки/test_stress.py`.

**Разбивка на трёх частях книги** (1, 7, 13 по 45 мин; 9 762 многосложных
слова; RUAccent уже исправлен; «вне словаря» - нет в словаре RUAccent на 3,19 млн
форм):

| род слова | слов | доля | расстановщики расходятся |
|---|---|---|---|
| словарное | 8 721 | 89,3 % | 159 (1,8 %) - почти всё служебные «или», «это», «через», которые RUAccent нарочно оставляет без «+» |
| омограф | 547 | 5,6 % | 65 (11,9 %) |
| **вне словаря** | **494** | **5,1 %** | **90 (18,2 %)** |

По всей книге слов вне словаря - 1 148 разных, 3 551 употребление. Это имена и
термины фантастики (Ксиухкоатль, Тенкатль, ланд-капитан, рэб-эскадра,
светосенсор), и именно там расстановщик угадывает - и расходится чаще всего.

Где расходятся чаще всего:

Полный список (174 разных расхождения) и тексты частей с ударениями обоих
расстановщиков - в `Архив/Ударения 3.0/` (не в репозитории: там текст книги).
Мест немного, поэтому список готов к слепой проверке, если понадобится.

**(б) Слушается ли модель «+».** Автоматически это не измерить: распознавание
речи пишет слова, а не ударения. Проверка - на слух, 30 фраз в слепом наборе
(п. 1.4): в каждой ударение проверяемого слова задано явно, у вариантов F5 и
Silero оно передаётся «+», у Qwen3 и Chatterbox (они «+» не понимают) - ставится
моделью самой.

### 1.2. Сравнение расстановщиков на открытой разметке

Тестовые наборы авторов закрыты: у RUAccent - 2 млн собственных предложений из
аудиоразметки, у silero-stress - валидация описана в вики, но не выложена. Взял
то, что размечено людьми и открыто: русские статьи английского Викисловаря
(выгрузка kaikki.org, CC BY-SA) - примеры-предложения с ударением во всех
словах и таблицы словоформ. Омограф - форма, у которой в Викисловаре больше
одного места ударения. Стенд - `Инструменты разработки/bench_stress.py`.

На одних и тех же 9 141 предложениях:

| | RUAccent turbo3.1 | silero-stress 1.5 | гибрид |
|---|---|---|---|
| омографы (8 574 слова) | 90,1 % | **91,9 %** | **91,9 %** |
| обычные слова (79 955) | 97,5 % | **99,2 %** | |
| - из размеченных расстановщиком | **99,4 %** | 99,2 % | |
| оставлено без ударения | 1 578 | 9 | |
| словоформы без контекста (5 000) | **98,2 %** | 97,3 % | |
| время на 10 тыс. предложений | 412 с | **20 с** | |

Оговорки: оба могли учиться на словарях, куда вошёл Викисловарь, поэтому
абсолютные числа завышены - но условия у обоих одинаковые. Разрыв в омографах
намного меньше заявленного авторами silero (0,92 против 0,76).

**Выбор.** Основа - RUAccent: в обычных словах он точнее, и, по всей видимости,
модель F5 дообучалась на разметке именно в его стиле (служебные слова без «+»).
В омографах (и ё-омографах «все/всё») берётся выбор silero-stress - +1,9 п. п.
Лишний «+» перед «ё», который ставит silero, убирается. Если silero-stress не
загрузится, работает один RUAccent, как раньше.

### 1.3. Единообразие внутри книги

`core/stress.py: unify_book()`: для слов вне словаря (не омографов) собираются
все варианты по книге, берётся самый частый (при равенстве - встреченный
раньше) и ставится везде. На «Жажде власти»: выровнено 19 слов в 35 местах
(«ланд-капитан», «ланд-майор», «ноль-перехода», «кихуатон»…). Время - 0,1 с на
книгу.

### 1.4. Слушается ли модель «+» - 30 фраз

13 пар омографов (замОк/зАмок, стЕны/стенЫ, мУку/мукИ, дОроги/дорогИ, бЕлки/белкА,
Атлас/атлАса, оргАн/Орган, плачУ/плАчу, вискИ/вИски, хлОпка/хлопОк, ужЕ/Уже,
слОва/словА, стрЕлки/стрелкИ, пОлки/полкИ) плюс «Её ещё нет, но всё будет
готово» и «звонИт». Лежат в слепом наборе (папка «4 Тридцать фраз»), список -

### 1.5. Буква «ё»

Проверено по всей цепочке: нормализатор ничего не теряет, RUAccent даже
восстанавливает «её» из «ее», словарь модели F5 содержит «ё» и «Ё», токенизатор
передаёт её как есть. «Всё / все», «её», «ещё» доходят до синтеза с «ё».

## 2. Качество голоса

Голос-образец у всех клонов один - Вячеслав Герасимов. Финальная обработка у
всех одинаковая (наш тракт HD_FILTER), громкость выровнена до -18 LUFS
(получилось -18,2 ± 0,1), mp3 192 кбит/с, 48 кГц. Буквы раздавались случайно.
