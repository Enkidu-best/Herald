## 2. Съеденные окончания и щелчки в конце фразы

Причина оказалась не в запасе длительности (он и так +22 %, больше
рекомендованных 5-8 %), а в обрезке хвоста куска:
- конец куска искался по порогу громкости, и тихое безударное окончание
  («правил[о]») отрезалось вместе с тишиной;
- срез шёл без затухания - ступенька из звука в нули паузы и есть щелчок;
- проверка последнего слова была нечёткой («правил» против «правило» - схожесть
  0,92, проходило) и запускалась только при тихом крае.

Сделано (общее):
- конец речи ищет **Silero VAD** (ONNX из Scribe, MIT), срез не раньше прежнего
  - звука только больше; затухание 25 мс в конце куска, 5 мс нарастания в начале;
- кусок без знака препинания в конце получает точку;
- конец проверяется **всегда и строго**: последнее слово должно совпасть вместе с
  окончанием, иначе кусок переозвучивается (до двух раз).

Замер «было -> стало»: 35 кусков (30 фраз + повествование + диалог), **одно и то
же зерно случайности** на кусок в обоих режимах - разница только от правок.
Последнее слово - по Whisper large-v3-turbo (независимо от проверки в программе).

| | неполное последнее слово | кусков со щелчком в конце | резких скачков в последних 100 мс |
|---|---|---|---|
| B16 было | 3 из 35 | 2 | 121 |
| **B16 стало** | **1** | **1** | **3** |
| C16 было | 1 | 0 | 0 |
| **C16 стало** | **0** | **0** | **0** |

Оставшееся у B16: «слышишь» в диалоге (распознано «слышь») и фраза «дороги»
(распознано «дорогие») - похоже на ошибку распознавания, слышно в мини-наборе.
Время счёта почти не изменилось (616 -> 585 с у B16, 540 -> 573 с у C16).
Стенд - `measure_edges.py`.

## 3. Числа, сокращения, инициалы

Сравнил на 50 предложениях с эталоном (числа в падежах, даты, века, проценты,
единицы, дроби, суммы, аббревиатуры, инициалы; `bench_normalize.py`):

| нормализатор | верно из 50 |
|---|---|
| наш прежний `normalize.py` | 22 |
| RUNorm small (Den4ikAI) | 27 (падает на римских цифрах, «Т. е.» -> «Так», «А. П.» -> «акционер») |
| ru-normalizr по умолчанию | 43 |
| **ru-normalizr + буквы и инициалы** - в программе | **47** |

Теперь: «везла 1250 руб.» -> «везла **одну** тысячу двести пятьдесят **рублей**»,
«3,5 кг» -> «три целых пять десятых **килограмма**», «в XXI веке» -> «в двадцать
**первом** веке», «МГУ» -> «эм гэ у», «А. П. Чехов» -> «а пэ Чехов». Аббревиатуры,
которые читаются словом (ВУЗ, МИД, ГОСТ), ru-normalizr определяет сам по общему
правилу. Остались: «не хватало два рублей» (родительный после отрицания), «ООН»
-> «о он», «США» -> «сэ шэ а» (разговорное, допустимо).

Встроено общим способом: ru-normalizr идёт первым по абзацам, наш разбор -
запасной и доделывает остальное. Одна тонкость: ru-normalizr ставит точку в конце
абзаца без знака, а заголовок главы конвейер узнаёт по её отсутствию - такую
точку снимаю. Скорость - около 2 с на книгу. Лицензия MIT.

Ещё по ходу: RUAccent склеивал тире реплики со словом («- Ты» -> «-Ты»), модель
видела не реплику, а слово с дефисом. Пробел возвращается (общее правило: слова с
дефиса не начинаются).

## 4. Ударения в омографах

**Сначала - моя ошибка.** В 30 фразах слепого набора этапа 1 эталонное ударение я
вписывал сам, и в четырёх фразах вписал неверно, а модель честно прочитала мой
знак:

| фраза | я задал | верно |
|---|---|---|
| 7. Все дороги вели к морю | д+ороги | дор+оги |
| 12. Платье сшито из атласа | ат+ласа (плюс перед согласной - испорченный знак) | атл+аса |
| 23. Эти слова запомнились | сл+ова | слов+а |
| 24. Не сказал ни слова | слов+а | сл+ова |

То есть «дороги», «слова» и «ни слова» из ваших замечаний - не ошибки
расстановщика, а мои. Эталон исправлен.

**Ошибки рода (б).** В фразах 1, 5, 9, 11, 22 («замОк», «мУку», «бЕлки», «Атлас»,
«Уже») модель получила **верный** знак «+» - и прочитала неверно. Это не текст, а
модель: F5 иногда не слушается ударения в омографе, склоняясь к более частому
варианту. Ни расстановщик, ни языковая модель-судья этого не исправят - знак и
так правильный. Общего лечения пока нет; открытый вопрос.

**Языковая модель как третий судья** (`core/homograph_llm.py`, Ollama qwen3.5:9b,
`bench_homograph_llm.py`). На 7 087 омографах Викисловаря:

| | омографы | 30 фраз (исправленный эталон) | время на книгу |
|---|---|---|---|
| RUAccent | 90,5 % | 27 | - |
| **RUAccent + silero (как сейчас)** | **91,0 %** | **27** | - |
| + модель только там, где они расходятся (968 мест) | 91,4 % | 28 | ~20 мин и 6,6 ГБ памяти |
| модель решает всё сама | **55 %** | 20 | ~2,5 ч |

Сама по себе модель ставит ударение на уровне монетки (55 %). Её прибавка на
расхождениях - 0,4 п. п. (около 28 слов из 7 087), то есть на уровне случайности,
а стоит 20 минут и 6,6 ГБ на книгу. **В программу не включено**; код оставлен
выключенным с этим объяснением.

## 5. Голоса

### 5.1. Образец Вячеслава

**Правило отбора образца** (`core/engines/f5.py`, общее, без списков): фрагмент не
берётся, если
- слов вне словаря (3,2 млн форм RUAccent) больше 10 %;
- средняя уверенность Whisper по фразе ниже -0,6 или есть повторы;
- похоже на стихи или перечисление (заглавные буквы посреди фразы - так Whisper
  записывает строки стихов).
Прежний образец («Бабаля, мальчик, трестень…») по этому правилу отсекается (29 %
слов вне словаря). Если годного куска нет вовсе - берётся лучший из негодных с
предупреждением в журнале.

(Отклонение от задания: «словарь silero-stress» не выложен отдельно - внутри
n-граммная модель, поэтому словарь - RUAccent, тоже 3,2 млн форм.)

Новые образцы из прозы и проверка гейтом против записи 1 (металл 0,062, F0 134):

| образец | металл | F0 | воздух | свист | слов распознано (повест./диалог) | гейт |
|---|---|---|---|---|---|---|
| прежний (стихи, запись 1) | 0,058 | 132 | 1,04 % | 6,9 дБ | 98,8 / 100 % | проходит |
| **проза, «Вячеслав Герасимов 2.mp3»** | 0,002 | 108 | 0,98 % | 9,1 дБ | 97,6 / 98,5 % | проходит |
| проза, «Олеся» | 0,255 | 119 | 0,12 % | 5,9 дБ | 97,6 / 100 % | **не проходит** |

По числам прежний ближе к живому голосу (высота 132 против 108; запись 2 - 32
кбит/с с обрезанным на 8 кГц верхом, отсюда «металл ноль»). «Олеся» не годится:
её зернистый после шумоподавления верх переходит в клон. Решает слух - пара в
`Сравнение голосов 3.0 - образец/`. Образец из прозы ещё и быстрее: 1,45 с счёта
на секунду звука против 1,94 (реже переозвучка краёв). В программе он есть как
голос «Вячеслав Герасимов (проза)»; рабочим остаётся прежний до вашего решения.
