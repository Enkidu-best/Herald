# Задание для Claude Code - Herald 3.3: проверка слов по звуку

Основа: прослушивание Андрея 15.10, папки перенесены в `Архив/Сравнения голосов 3.2/`.

## Решения

- **ESpeech - 12 шагов.** Варианты почти одинаковые; на 16 «совсем чуть-чуть металла», на 12 ошибок не больше.
- **Строгая проверка 3.2 на слух дала смешанный результат:**
  - диалог с Марией - лучше («ты правда думаешь, что вернётся» - но пропало «он»: в тексте «что он вернётся»);
  - короткие фразы второй части - **хуже**, чем в 3.1: «покрытый напылением гражданско…», «я ответил» слилось в «яответил».

  Цена при этом +50-58 % времени. Значит, нынешний способ проверки ловит не то.

## Почему проверка не видит ошибок, которые слышит Андрей

Whisper - не «уши», а модель с сильной языковой догадкой: он **дописывает** правдоподобное слово по смыслу. Модель произнесла «Патлся… актив…» - Whisper пишет «активировал». Сравнение текста с текстом ошибку не находит. Это уже видели в 3.1: 64 из 66 обрубленных слов Whisper «услышал» целыми.

Ошибки, которые Андрей отметил на слух - **размеченный набор** для настройки (не правила под слова):

| файл | место | что слышно |
|---|---|---|
| ESpeech, вариант О | «…короткой серией на… активировал» | последнее слово непонятно |
| ESpeech О и С | «он упал …» | следующее слово неразборчиво |
| ESpeech О и С | «отшвыривая ногой» | «ногой» нечётко («новой») |
| ESpeech С | «через плечо. Куда…» | «куда» съедено |
| слова, 3.1 | «ты правда думаешь…» | «думаться» |
| слова, 3.1 и 3.2 | «покрытый напылением гражданского…» | обрыв |
| слова, 3.2 | «я ответил» | слитно |
| слова, 3.2 | «что он вернётся» | пропало «он» |

## 1. Проверка по звуку, а не по догадке

Заменить сравнение «текст Whisper ↔ текст книги» на **принудительное выравнивание (forced alignment)** текста книги по звуку моделью без языковой догадки:
- кандидат - CTC-модель для русского по буквам или фонемам (например wav2vec2-xlsr для русского или MMS-alignment), локально, офлайн, лицензия - в README;
- для каждого слова получаем оценку, **насколько звук похож на это слово**. Низкая оценка - слово съедено или смазано;
- слитые слова («яответил») видны по отсутствию паузы между словами там, где в тексте пробел после знака препинания или на стыке реплики.

**Порог** подобрать на размеченном наборе выше плюс на чистых местах из тех же файлов, где Андрей ошибок не слышал:
- поймать ≥ 80 % отмеченных мест;
- ложные срабатывания ≤ 5 % кусков.

Если цифры недостижимы - написать честно, какой лучший размен.

**Лечение** - как сейчас: пересчёт куска с другим зерном, до 2 попыток, берётся вариант с лучшей **минимальной** оценкой слова (а не средней).

## 2. Длина куска

Проверить, не дают ли длинные куски больше смазанных слов. Сравнить по новой оценке из п. 1, на одной главе:
- текущая длина;
- примерно 2/3 от неё.

Учесть скорость: короче кусок - больше накладных на образец. Взять, только если ошибок заметно меньше.

## 3. Что по умолчанию

- Если новая проверка на размеченном наборе лучше старой и прибавка времени ≤ 25 % - **включена по умолчанию**, старую строгую убрать.
- Если нет - строгая проверка 3.2 **выключена** по умолчанию (на слух выигрыша нет, а время +50 %), настройка остаётся.

## 4. Андрею на слух

Тот же отрывок главы и те же фразы «слова», вслепую, два варианта: 3.2 без проверки и 3.3 с новой проверкой. Ключ - в `docs/`.
