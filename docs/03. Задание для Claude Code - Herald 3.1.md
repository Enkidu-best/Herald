# Задание для Claude Code - Herald 3.1

Основа: оценки Андрея 14.10 по мини-наборам и разбор дизайн-чатом по ключам.

## Решения Андрея

- **Основной движок - B16** (вариант С на главе: «всё отлично - произношение, звук, ударения, диалоги»). C16 (Ф) - чуть больше шума или металла. C16 остаётся в Настройках как запасной со свободной лицензией. Папку `.venv-candidates` удалить.
- **Образец Вячеслава - прежний** (К, стихи): «звучит значительно чище». Образец из «Вячеслав Герасимов 2.mp3» (М) - шум, металл, хрип; по замеру у этой записи обрезан верх.
- Ударения на главе - «везде отлично».

## 1. Образец: правило отбора не должно ломать выбор Андрея

Правило из этапа 2 (больше ~10 % слов вне словаря - фрагмент не брать) отсекает образец, который Андрей выбрал на слух. Значит:
- правило работает только при **автоматическом** отборе нового образца; уже выбранный голос не трогать;
- **ещё одна попытка прозы**: сделать образец из «Вячеслав Герасимов 3. Куприн - Олеся.m4b» по тем же правилам (без обрезанного верха - проверять это при отборе: срезанные вершины волны, спектр выше 8 кГц). Мини-сравнение вслепую с К, два файла. Если К снова лучше - остаёмся на К и больше к этому не возвращаемся;
- громкость −1 дБ (volume 4 → 3 дБ) - только если победит образец из прозы: проблема касания потолка была у него.

## 2. Съеденные окончания - главное

Андрей всё ещё слышит потери на концах кусков:
- «(бес)конечных интри(г)»;
- «я просто устал жда(ть)»;
- «(ему) в голову не вы(йдет)».

Автозамер «неполное последнее слово» этого не ловит, значит, он недостаточно строгий.

2.1. **Сначала диагноз по каждому из трёх мест.** Найти исходный кусок, послушать или проанализировать **сырой выход модели до любой обработки**:
- **(а) звук в сыром выходе есть, пропадает после обработки** → виновата обрезка или склейка;
- **(б) звука нет уже в сыром выходе** → модель недоговаривает.

Записать, какой случай где.

2.2. **Лечение (а):**
- хвост куска **не резать по громкости вообще**: глухие «г», «т», «ть» на конце - самые тихие звуки речи, любой порог их съест;
- обрезать только явную тишину, начиная не раньше чем через 150-250 мс после конца речи по Silero VAD;
- плавное затухание 20-30 мс на самом краю (уже есть - проверить, что оно идёт **после** запаса, а не по звуку).

Учесть: паузы между кусками уже задаются отдельно (0,4 / 0,8 / 1,1 с), поэтому запас на хвосте вычитать из следующей паузы, чтобы паузы не выросли.

2.3. **Лечение (б):**
- запас длительности при синтезе (+5-10 %, подобрать);
- проверка последнего слова строже: сравнивать не всё слово целиком, а **его конец** - последние 2-3 буквы по ASR с текстом. Если не совпало - пересинтез с бо́льшим запасом.

2.4. **Регресс-набор:** эти три фразы плюс 30 фраз на концы с глухими согласными («-г», «-к», «-т», «-ть», «-сть», «-кт»), всё в конце куска. Отчёт «было → стало» для B16. Плюс два-три коротких файла для Андрея **на слух** - автозамер уже раз ошибся.

## 3. Скорость: что реально, а что нет

Андрей спрашивает, почему 2 минуты счёта на минуту звука и можно ли быстрее без потери качества.

Что уже проверено и **не помогает** (README, раздел «Скорость»):
- квантование весов 8/4 бита: расчёт упирается в арифметику, а не в память;
- float16/bf16;
- два процесса;
- куски длиннее 200 символов: падает разборчивость.

Повторно это не делать.

**32 шага в Настройки не выводить:** в слепом сравнении 32 шага были хуже 16, съедали окончания.

Что проверить (замер скорости + на слух, вслепую, если меняется звук):
1. **Пакетная обработка** - несколько кусков одной длины в один вызов сети. Видеоядро загружено примерно на 56 % от пика, пакет может добрать часть. Замерить прирост честно.
2. **Конвейер** - пока видеоядро считает кусок N, процессор готовит текст N+1 и кодирует N−1.
3. **Длина образца.** На каждом вызове модель заново прогоняет образец (около 10 с звука). Образец 7-8 с вместо 10-12 даёт меньше счёта на каждый кусок. Проверить на слух вслепую: не теряется ли сходство голоса.
4. **12 шагов вместо 16** - вслепую против 16 на главе. Только если на слух не отличить.

Ориентир честно: на M4 ускорение без потери качества - скорее десятки процентов, чем в разы. Книга на ночь - нормальный режим. «Продолжить» и запрет сна уже есть.

## 4. Паузы

Пауза между репликами диалога уже 1,1 с, и на главе Андрей сказал «диалоги хорошо». Вывести три паузы в Настройки (конец предложения, абзац, между репликами) с текущими значениями по умолчанию. Значения не менять.

## 5. Окно

5.1. **Голоса.**
- Убрать кнопку «Звучание».
- Карточка голоса целиком кликабельна: при наведении - подсветка, при щелчке - выбран, и справа открываются его настройки (темп, высота, бас, яркость, «Прослушать»).

5.2. **Мини-плеер у готовой части** вместо одной кнопки «Слушать»:
- «Играть / Пауза» - одна кнопка-переключатель;
- «Стоп»;
- прошло / всего («1:12 / 45:00»);
- ползунок перемотки.

Играет один файл за раз: запуск другой части останавливает текущую. При закрытии окна звук останавливается.

Проверить в обеих темах, снимки в отчёт.
