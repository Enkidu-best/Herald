# Задание для Claude Code - Herald 3.2

Основа: оценки Андрея 15.10 по четырём папкам «Сравнение 3.1» (папки перенесены в `Архив/Сравнения голосов 3.0-3.1/`) и разбор по ключам.

## Решения Андрея (по ключам)

| Сравнение | Победил | Значит |
|---|---|---|
| Окончания | «Стало (3.1)» - «ничего не съедается, всё чётко» | лечение 3.1 оставить |
| Образец: К или «Олеся» | **Д = К** («очень хорошо»); «Олеся» - глуховато, металл в паузах, каша в словах | остаёмся на К. **К прозе больше не возвращаемся** |
| Длина образца: 10 с или 6,8 с | **О = 10 с** («интонация богаче, растягивает слова как автор»); 6,8 с - металлический призвук | образец не укорачивать, ускорение на 35 % не берём |
| Шаги: 16 или 12 | **В = 12** («восклицания без крика, некоторые слова произносятся лучше») | **по умолчанию 12 шагов**: счёт на 25 % быстрее |

Итог по скорости: час звука - около 1 ч 20 мин вместо 1 ч 50 мин. В окне - честная оценка по замеру.

## Часть 1. Звук

1.1. **12 шагов по умолчанию** для основного движка (B, Misha). Для ESpeech - проверить, не хуже ли на 12, и если на слух нет разницы - тоже 12. В Настройках названия без цифр: «Основной (рекомендуется)», «ESpeech (свободная лицензия)», «Черновик».

1.2. **Ударения**, найденные Андреем на главе:
- «ск+ользя» (нужно скольз+я);
- «выхв+атил» (нужно в+ыхватил);
- «л+огично» (нужно лог+ично).

Это обычные слова, не омографы. Для каждого выяснить: неверный знак «+» в тексте или модель не послушалась. Лечить общим способом, без словаря исключений:
- если ошибка в знаке - разобраться, почему словарный RUAccent ошибся (форма слова, соседняя пунктуация, ё);
- если модель - записать в отчёт как свойство модели.

1.3. **Неразборчивые и пропавшие слова в середине куска.** Андрей слышит: «он правда вернётся» - «вернётся» неразборчиво в обоих вариантах, «давай» плохо слышно. В 3.1 также найден пропуск «и огляделся» в длинном куске. Сейчас проверка смотрит только первое и последнее слово.

Сделать общую проверку **всего куска**:
- распознать кусок (Whisper turbo, язык известен);
- выровнять со словами текста;
- если слово пропало или искажено (по последним буквам, как для окончаний) - пересинтез куска с другим зерном (seed), до 2 попыток, затем лучший вариант по числу совпавших слов.

Помнить урок 3.1: распознаватель сам «дописывает» обрубленные слова, поэтому сверять по буквам, а не по смыслу.

Замер:
- доля кусков с пересинтезом;
- прибавка ко времени книги;
- было → стало по пропущенным словам на главе.

Если прибавка больше ~20 % - сделать проверку настройкой «Строгая проверка слов (дольше)», по умолчанию включена. Итог - Андрею на слух: 2-3 файла «было / стало» на тех же местах.

## Часть 3. Windows и Linux (после частей 1-2)

По образцу Scribe 2.4 (`../Аудио в Текст/docs/03. Задание…`, `docs/Приёмка 2.4.md` - взять готовые решения, а не придумывать заново):

1. **Слой движка** - автоматически, без выбора у пользователя:
   - Apple Silicon - MLX (как сейчас);
   - NVIDIA - torch CUDA: движок `f5.py` уже есть, проверить ту же модель, 12 шагов и обработку краёв 3.1;
   - процессор - работает, но честно: озвучка книги на процессоре - сутки и больше. В окне предупреждение и предложение готовых голосов Silero, они быстрые и на процессоре.
2. **Пути, открытие файлов, запрет сна:** Windows - `SetThreadExecutionState`, Linux - `systemd-inhibit` или аналог. Плеер - проверить на Windows.
3. **Установщик .exe** через GitHub Actions (как Scribe): ffmpeg внутри; модели при первом запуске или офлайн-пакетом; ускорение NVIDIA - отдельной докачкой.

   **Голоса пользователя (образцы) в установщик не класть** - это чужие записи. Пользователь добавляет свой образец кнопкой «Добавить образец…». Silero - в установщике или докачкой, с пометкой о некоммерческой лицензии.
4. **Проверки:**
   - Linux в Docker на этом Mac (процессор): пробник 1 минута, ударения, нормализация, окончания;
   - Windows на раннере GitHub: установка → пробник → удаление.

   Окно и звук на настоящей Windows проверить нельзя - чек-лист для Андрея.
5. **На Mac звук и скорость не должны измениться** - повторить замеры 3.1 (окончания, паузы, RTF).
