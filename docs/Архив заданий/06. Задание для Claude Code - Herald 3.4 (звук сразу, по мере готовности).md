# Задание для Claude Code - Herald 3.4: звук сразу, по мере готовности

Прочитай `docs/Правило - Mac, Windows, Linux и сервер.md` (если в Herald его нет - в соседнем «Legal Doc Builder/docs»): всё, что делаем, должно работать на всех трёх системах. Тяжёлые шаги на видеокарте - только под общей блокировкой `../.heavy-lock` (mkdir, файл владельца, rm -rf после шага; блокировку старше 3 часов без живого процесса владельца можно снять).

## Зачем

Сейчас звук слышен только когда готово всё: пробник на минуту ждём 1,5-2 минуты, «Прослушать» в «Голосах» - пока не досчитается вся фраза. Облачные сервисы начинают говорить почти сразу: синтезируют по предложениям и играют первое, пока считаются следующие.

Делаем так же. Модели не меняем - меняем порядок: **считать по кускам и играть, как только можно**.

Важно: клон F5 на Mac считает медленнее реального времени (RTF 1,4-1,8 по приёмке 3.3). Если начать играть сразу, звук будет запинаться. Поэтому нужен расчёт старта (п. 2). Готовые голоса Silero считают намного быстрее реального времени - у них звук почти мгновенный.

## 1. Общий механизм «синтез потоком»

Один модуль в `core` (не копии в окне и CLI):
- текст режется на куски по предложениям, как сейчас (`_chunk_paragraphs`, `sentenize`); **первый кусок - короткий** (одно предложение до ~80 знаков), чтобы первый звук пришёл быстро;
- куски считаются по очереди в фоне и кладутся в очередь;
- плеер (`player.py`, Mac - AVAudioPlayer, Windows/Linux - sounddevice) играет из очереди без щелчков и с теми же паузами между кусками, абзацами и репликами, что в книге;
- те же ударения, нормализация, эффекты голоса (`fx`: темп, высота, яркость), что в обычной озвучке. Эффекты ffmpeg применять к каждому куску или потоком - выбрать по качеству на стыках;
- кнопки: пауза, стоп. Стоп сразу прекращает и синтез, и звук;
- по окончании весь звук сохраняется в файл, как сейчас (пробник в списке рядом с книгой), - ничего из нынешнего поведения не теряем.

## 2. Когда начинать играть

- Скорость (RTF) движка с этим голосом мерить по первым кускам и запоминать по профилю и голосу (между запусками).
- Старт - когда оставшийся счёт успеет до конца звучания: «уже готовый звук + звук, который досчитается за время игры ≥ длина всего фрагмента». Плюс запас 10 %.
- Если всё-таки не успели (машина занята) - короткая пауза на границе предложения, не посреди слова.
- В окне: «Звук начнётся через ~N с» с обратным отсчётом, потом «Играет · считаю дальше».
- Проверка слов по звуку (3.3) в режиме потока: для пробника - как в книге (включена); для коротких фраз и п. 4 - выключена (+19 % времени, а это прослушивание, не готовая книга). Если проверка заменила кусок, а он уже прозвучал - ничего не делать, в итоговый файл идёт исправленный.

## 3. Где включить

1. **Главная, «Проверить голос (1 мин)»** - звук идёт по мере готовности, итоговый файл - как сейчас.
2. **Голоса → «Прослушать»** (эффекты голоса) - то же для фразы `FX_PHRASE`. Кэш сырого звука `_fx_raw` при смене только эффектов сохранить: повторное прослушивание с новыми ползунками - мгновенно.
3. **Настройки, проверка голоса при выборе** - тот же механизм.

## 4. «Прочитать вслух» - новый быстрый режим

На главной - поле «Прочитать текст» (вставить текст или кнопка «Из буфера») и кнопка динамика. Звук сразу, в файл не сохраняется (кнопка «Сохранить» после прослушивания - по желанию).
- Голос: выбранный (клон) или «Быстрый» (готовый голос Silero) - переключатель рядом с кнопкой. По умолчанию для этого режима - быстрый.
- Русский и английский по тому же определению языка, что в книге.

## 5. Озвучка для других программ

Чтобы кнопку динамика можно было поставить в Legal Knowledge Desk и будущем помощнике по настольной игре:
- в `cli.py` - режим `--speak "текст"` (или из stdin) с той же потоковой игрой;
- **локальный сервис** (только 127.0.0.1, порт в настройках, по умолчанию выключен): `POST /speak` {text, voice, fast} → звук потоком (по кускам, WAV/PCM), `POST /stop`. Сервис поднимается из окна (Настройки → «Озвучка для других программ») или командой. Без интернета, без облака. Описать в README, как вызвать из другой программы (пример на Python и на JS из браузера).
- Модель держать загруженной, пока сервис включён; выгружать через N минут простоя (настройка).

## 6. Время первого звука - цели (Mac, замерить)

| что | цель первого звука |
|---|---|
| «Быстрый» голос Silero, фраза | ≤ 0,7 с |
| клон F5, фраза ~10 с звука, модель уже загружена | ≤ 3 с |
| клон F5, пробник 1 мин | в 2 раза раньше, чем сейчас весь пробник, и без запинок |
| `/speak` из другой программы, Silero | ≤ 1 с от запроса |

Если клон F5 не укладывается в 3 с на фразе - проверить, что даёт отдельный «живой» профиль с меньшим числом шагов (8 против 12): время и слепое сравнение пары на одной фразе (как раньше: `build_pair.py`, ключ - в отдельный файл «не открывать до оценки»). Включать по умолчанию - только после моей оценки.

На Windows и Linux - тот же замер (через CI или Docker, как в 3.2), цели - те же для Silero; для F5 на процессоре - только отчёт о времени.
