# Herald - продукт

Описание «как есть» по коду на 22.10.2026 (коммит 6530ee4, в окне - версия 3.8). Подробности - в `Функциональное описание.md`.

## Зачем

Herald превращает книгу в аудиокнигу прямо на компьютере Андрея: без интернета (кроме разовой загрузки моделей), без подписок, текст никуда не уходит. Книгу читает голос, клонированный из записи нужного чтеца, или готовый быстрый голос. Программа сама разворачивает числа и сокращения в слова и сама расставляет ударения. Книга считается часами, поэтому её ставят на ночь, а первые части слушают, пока считаются остальные.

## Для кого

Для Андрея - личное использование на его Mac (Apple Silicon). Код работает и на Windows / Linux (видеокарта NVIDIA или процессор), но там окно и звук вживую не проверены. Вторые «пользователи» - другие программы Андрея на этом же компьютере (Interview Coach, Legal Knowledge Desk): они просят Herald прочитать текст через локальный сервис `/speak`.

## Главные сценарии

| № | пользователь хочет… | делает… | получает… |
|---|---|---|---|
| UC-01 | послушать книгу голосом любимого чтеца | перетаскивает книгу в окно, выбирает голос, длину частей и формат, нажимает «Озвучить книгу» | папку рядом с книгой: «Часть 01.mp3», «Часть 02.mp3»… (или один файл); готовые части можно слушать в окне, пока считаются остальные |
| UC-02 | не ждать часы зря | нажимает «Проверить голос (1 мин)» | минуту звука из книги сразу по мере готовности и файл «<книга> - пробник.mp3» рядом с книгой |
| UC-03 | убедиться, что ударения и числа прочитаются верно | нажимает «Как будет прочитано» | окно с текстом книги так, как он уйдёт в модель: ударения - знаком над гласной, спорные слова подсвечены |
| UC-04 | завести голос нового чтеца | на странице «Голоса» - «Добавить образец…», выбирает запись и имя | новый голос-клон в списке; справа - его звучание (темп, высота, бас, яркость) |
| UC-05 | продолжить книгу после остановки или сбоя | открывает ту же книгу с теми же настройками и нажимает «Продолжить (k из N)» | озвучка идёт с того места, готовые части не пересчитываются |
| UC-06 | быстро прослушать любой текст | на странице «Прочитать вслух» вставляет текст и нажимает «Прочитать» | звук почти сразу, звучащее предложение подсвечено; можно сохранить прочитанное в mp3 |
| UC-07 | дать голос другой своей программе | в Настройках включает «Озвучка для других программ» | другие программы на этом компьютере шлют `POST /speak` и получают звук потоком |

## Что Herald не делает

- Не распознаёт сканы (PDF без текстового слоя пропускается - OCR нет).
- Не даёт править ударения руками: ручного словаря ударений нет и не будет (решение Андрея); ударения ставятся только автоматически.
- Не меняет интонацию и манеру чтения: они приходят из образца голоса.
- Не озвучивает несколько книг одновременно и не ведёт очередь книг.
- Не отправляет ничего в интернет; сервис `/speak` отвечает только программам на этом же компьютере (127.0.0.1).
- Из окна не собирает единый файл аудиокниги `.m4b` с обложкой - это есть только в консоли (`cli.py --m4b`).
- Не поставляет звук: образцы голосов, записи чтецов и сравнительные записи в программу не входят.

## Ограничения

- **Только для личного использования.** Голоса настоящих чтецов (Игорь Ященко, Вячеслав Герасимов, в том числе дообученные на их записях) и голоса «Диктор 1-3» / «Голос 01-04» сделаны из чужих записей - их нельзя распространять и использовать вне личных целей. Основной движок F5 (веса Misha24-10) и голоса Silero - лицензии некоммерческие; для продукта годились бы только ESpeech, Vosk и Piper (движок Piper - GPL-3.0, ставится отдельно).
- Скорость: на Apple M4 час звука клоном считается около 1 ч 20 мин - 1 ч 25 мин; на процессоре - около суток на час звука.

## Метрика успеха (как её меряют сейчас)

1. **Слух Андрея - главный критерий.** Голос, движок и настройки выбираются слепым прослушиванием; числа только отсекают брак (они не раз расходились с ухом).
2. Книга досчитывается за ночь без вмешательства: без потерянных слов и обрезанных окончаний (их ловит проверка слов по звуку и пересчёт куска).
3. Ударения верные без ручных правок; имя героя звучит одинаково во всей книге.
4. Прогноз «Ждать около…» близок к факту (программа запоминает настоящую скорость на этом компьютере).
