## Часть 1. Звук

### 1.1. 12 шагов по умолчанию

- Основной движок (Misha) - **12 шагов**, по вашему выбору 15.10. Счёт на 25 %
  быстрее: RTF 1,36 против 1,80 на 16 шагах (без проверки слов).
- В Настройках названия без цифр: «Основной (рекомендуется)», «ESpeech
  (свободная лицензия)», «Черновик».
- ESpeech: оставлен на 16 шагах до вашего прослушивания пары 12/16
  (`Сравнение 3.2 - ESpeech/`). Если на слух не отличить - переведу на 12.
- Прогноз «ждать около» запоминается отдельно для числа шагов, вычислителя и
  строгой проверки: старый замер для 16 шагов не путает новый.

### 1.2. Ударения «скользя», «выхватил», «логично»

Проверил весь путь текста до модели на той же главе. **Во всех трёх местах знак
«+» верный** - и в словаре RUAccent, и в куске, который ушёл в модель:

| слово | словарь RUAccent | в куске, отданном модели |
|---|---|---|
| скользя | скольз+я | «…соглас+ился пил+от, скольз+я взгл+ядом…» |
| выхватил | в+ыхватил | «…и пил+от в+ыхватил с держ+ателей…» |
| логично | лог+ично | «- Лог+ично, - соглас+ился пил+от…» |

Значит, это **модель не послушалась верного знака** (то же, что род (б) в 3.0:
«замОк», «мУку») - свойство модели F5 Misha, а не ошибка текста. Общего лечения
нет; словарей под слова не делал.

### 1.3. Неразборчивые и пропавшие слова в середине куска

Сделана **строгая проверка всего куска**: кусок распознаётся целиком (Whisper
large-v3-turbo, язык известен), слова выравниваются с текстом, и каждое
словарное слово от 4 букв сверяется **по последним буквам** (урок 3.1:
распознаватель дописывает обрубленное по смыслу). Пропало или искажено - кусок
пересчитывается с другим зерном, до двух раз, затем берётся дубль с наименьшим
числом неверных слов. Выдуманные имена книги («Экстервит») не сверяются - их
нет в словаре, и распознаватель пишет их как попало (иначе каждый кусок с
именем пересчитывался бы впустую). Края куска проверяются как прежде.

Замер (отрывок главы 4 мин + диалог + тестовый диалог, одно зерно; судья -
Whisper large-v3, НЕ turbo, чтобы не мерить проверку ею же):

| | было (3.1) | стало (3.2) |
|---|---|---|
| пропавших или искажённых слов по судье | **9** | **5** |
| - отрывок главы | 4 | 5 |
| - диалог («…что он вернётся?») | 3, в т.ч. «вернётся» | 0 |
| - тестовый диалог («и огляделся») | 2, в т.ч. «огляделся» | 0 |
| кусков с пересинтезом | 1 из 21 | 6 из 21 |
| счёт (RTF) | 1,53 | 2,48 (**+62 %**) |

Прибавка больше 20 %, поэтому проверка - **настройка «Строгая проверка слов
(дольше)»**, по умолчанию включена (Настройки → «Проверка»). Честно: в главе
выигрыша нет (4 -> 5, слова другие - «запорное устройство», «сетчатку»), он
весь в диалогах. Решение за вашим слухом: `Сравнение 3.2 - слова/`.

## Часть 3. Windows и Linux

По образцу Scribe 2.4 (пути, открытие файлов, ffmpeg в установщике, окна
консоли, NVIDIA-докачка, Inno Setup и проверки в GitHub Actions взяты оттуда).

### 3.1. Слой движка - сам, без выбора у пользователя

| компьютер | синтез | распознавание (проверка, образец) |
|---|---|---|
| Mac, Apple Silicon | F5 на MLX (как было) | MLX Whisper |
| видеокарта NVIDIA | F5 на torch, CUDA (после докачки) | faster-whisper, CUDA |
| процессор | F5 на torch, процессор | faster-whisper, int8 |

**Torch-движок считает тем же алгоритмом, что MLX**: та же модель (Misha
accent_tune), 12 шагов EPSS, якорь тишины и хвост 3.1, длительность, темп,
проверка краёв и слов. Прежний `f5.py` шёл через готовый `f5_tts.api.infer` -
другой алгоритм, без якоря и без EPSS; он оставлен только для сверки. Сеть
DiT и мел - копия из F5-TTS (MIT, `core/engines/f5net`), без самого пакета
f5-tts: тот тянет gradio, datasets, wandb.

Сверка (`test_torch_parity.py`): один кусок, один начальный шум -
**мел torch и MLX совпадают до 0,0006** (размах 11,5). Сначала они расходились
на 49 %: исходный F5 на torch дополняет края мела отражением и оставляет
последний кадр, а MLX - нулями и кадр отбрасывает; сеть та же, но разные края
образца давали разный звук. Сделал мел как у MLX - теперь на Windows/Linux звук
тот же, что на Mac.

**Процессор** - честно: окно пишет «Считается на процессоре: час звука - около
суток счёта, книга - несколько суток. Быстро на процессоре работают готовые
голоса Silero», и прогноз «ждать около» считает по множителю процессора.

### 3.2. Пути, файлы, сон, плеер

- Журнал: Windows `%LOCALAPPDATA%\Herald\Logs`, Linux `~/.local/state/Herald/log`
  (Mac - как было). Голоса, кэш, модели - `~/.cache` на всех системах.
- Открыть файл / показать в папке: Проводник (`explorer /select`), `xdg-open`;
  кнопка у части - «В Finder» на Mac, «В папке» на Windows/Linux.
- Запрет сна: Windows - `SetThreadExecutionState` (из своего потока: флаг
  держится, пока поток жив), Linux - `systemd-inhibit`, Mac - `caffeinate`.
- **Плеер**: на Mac - AVAudioPlayer; на Windows/Linux - ffmpeg раскодирует
  с нужной секунды, звук через sounddevice. `test_player.py` проверяет оба
  способа на этом Mac: играть, пауза держит позицию, перемотка, стоп.
- Шрифт Segoe UI / DejaVu Sans, курсор-ссылка не только для Mac, у оконной
  сборки без консоли вывод уходит в журнал, ffmpeg без мигающих окон.
- Закрытие окна: выход без разбора объектов MLX/onnxruntime (урок Scribe).

### 3.3. Установщик Windows

GitHub Actions (`.github/workflows/release.yml`): PyInstaller (папка) +
Inno Setup, ffmpeg (сборка LGPL от BtbN) внутри. **Голосов пользователя в
установщике нет** - отдельный шаг сборки проверяет, что в ней нет ни mp3, ни
wav, ни книг; голос добавляется кнопкой «Добавить образец…». Модели - при
первом запуске (окно пишет «Скачиваю модели (первый запуск, около 3 ГБ…)»).
Silero - докачкой при первом выборе готового голоса; на странице «Голоса»
пометка «лицензия некоммерческая». Ускорение NVIDIA - отдельной докачкой
(сборка torch с CUDA с download.pytorch.org, ~2,5 ГБ, кнопка в Настройках
видна только на Windows с видеокартой NVIDIA). **На настоящей видеокарте не
проверено** - её нет ни у нас, ни на раннерах; проверено, что ссылка находится.
