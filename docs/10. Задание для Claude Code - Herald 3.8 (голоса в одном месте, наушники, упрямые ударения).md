## 1. Упрямые слова: модель не слушается «+»

Текст до модели верный, а модель читает по-своему. Андрей на «Пробе пера 4» (клон) и «3»: «о́тмель / о́тмели» (с о́тмели, на о́тмели), «ка́торжник», «ча́ек» (крик чаек), «долги́» (страховка, груз, долги), «по́черком», плюс «отмЕль» в слепых наборах.
- Найти **универсальный приём**, которому модель подчиняется, и проверить на этих словах и 30 других редких словах с ударением не на привычном месте: варианты - двойная отметка, ударная гласная отдельным слогом через дефис внутри токена, замена безударных «о» на «а» в произношении («атмель» → читается как надо, «о́» сохраняется ударной), ё-подобная запись и т. п. Слепой набор для Андрея: 10 слов × 2-3 приёма.
- **Всё автоматически, без ручных словарей** (решение Андрея 17.10: он ничего руками записывать не будет). Найденный приём программа сама применяет к словам с риском ошибки: редкие слова, слова с ударением не на «привычном» для модели месте (по частотному словарю и по тестовому набору модели), омографы. Список «трудных для модели» слов собирается и пополняется программой сама (прогоном тестового набора при установке / обновлении модели), не человеком.
- Ручной словарь и правку ударения в окне **не делать**; «Как будет прочитано» оставить только для просмотра.
- Слова, которые Андрей уже назвал, - в тестовый набор.

## 2. Голоса - всё в разделе «Голоса»

- Скачивание, удаление, «Послушать» **перенести из «Настроек» в раздел «Голоса»**; из «Настроек» убрать.
- **Каждый голос - отдельной строкой**, у каждой - «Послушать», «Скачать» / «Удалить», размер. Piper - по одному. Vosk: один файл модели на три голоса - показать это в строках («входит в пакет Vosk 747 МБ»); «Удалить» у одного голоса Vosk - скрывает его; когда скрыты все три - предложить удалить пакет.
- **Переименовать голос** - «✎» у названия: своё имя для показа во всех списках (клоны и стоковые), исходное имя - мелко серым; хранится в профиле.
- Удаление - в меню «⋯» строки (стандарт), с подтверждением.

## 3. «Прочитать вслух»

- **Одна кнопка «▶ / ❚❚»** вместо двух (пробел - то же самое).
- **Звук идёт не в наушники:** вывод должен идти на **текущее устройство системы** и переключаться на лету при подключении наушников / AirPods (не запоминать устройство при запуске). В «Настройках» - «Устройство вывода: Как в системе / …». Проверить на Mac с проводными и Bluetooth-наушниками и на Windows.

## 4. Прогноз

«Проба пера 3» второй раз (Герасимов): прогноз 2:19, факт **0:55** - части, видимо, взяты из готового (кэш синтеза). Прогноз должен учитывать готовые части: «12 из 15 частей уже готовы - около 0:50». Замеры кэша в прогноз скорости не записывать.
