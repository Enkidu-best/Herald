## 1. Скорость книги по умолчанию

- По умолчанию - **подсказка CFG на первых 6 шагах из 12** (RTF около 1,0; на слух ближе к нынешнему, чем 4 шага).
- В Настройках - выбор «Качество / скорость»:
  - **«Быстрее»** - 4 шага (RTF ~0,87);
  - **«Сбалансировано»** (по умолчанию) - 6 шагов;
  - **«Максимальное качество»** - 12 шагов, как в 3.5.
- **Прогноз времени:** не брать замеры, сделанные до смены режима и версии (хранить вместе с ними версию, режим и голос). Для голоса без свежих замеров - общий замер режима.
- **Замер в приёмке на «Проба пера 3», голос Ященко**, во всех трёх режимах: звук, прогноз, факт. Цель для «Сбалансировано»: ожидание ≤ 1,15 × длительность звука.

## 2. «Прочитать вслух» - быстрые голоса

- **Клон-голоса из этой вкладки убрать** по умолчанию: в Настройках флажок «Показывать клон-голоса в „Прочитать вслух“» (выключен). Переключатель «Быстрый / Клон» без клонов не нужен - сразу список голосов.
- **Больше быстрых голосов** (локальные, звук почти сразу на M4, свободная лицензия, русский и английский):
  - кандидаты: Piper (русские голоса и английские), Vosk TTS (русский, несколько дикторов), другие голоса Silero (если есть для ru / en);
  - отсев кодом (скорость первого звука ≤ 1 с, нет явного брака), потом **слепой набор** для Андрея: один и тот же абзац, все кандидаты под буквами, мужские и женские отдельно; ключ - «не открывать до оценки». Включаются только голоса, которые Андрей отметит;
  - в списке голоса подписаны: имя, муж. / жен., язык.
- **Темп:** диапазон шире - **0,5 … 1,5** (сейчас 0,8 … 1,25). Значение, сохранённое для голоса, - начальное положение ползунка (у Евгения - то, что выставил Андрей).
- **Подсветка звучащего предложения:** светлая заливка с тёмным текстом и в светлой, и в тёмной теме; проверить контраст (текст читается).
- **«Сразу» / «Без пауз»** - для быстрых голосов не показывать (они и так без пауз). Если включены клоны - подписи: «Начать сразу (между фразами возможны паузы)» / «Подождать и читать без остановок».
