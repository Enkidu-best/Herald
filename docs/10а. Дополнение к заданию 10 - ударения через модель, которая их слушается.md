# Дополнение 10а к заданию 10: ударения через модель, которая их слушается

Версия 18.10.2026. Делать, когда Андрей скажет «можно продолжать» (см. `../../Очередь проектов.md`). **Заменяет часть 1 задания 10.** Части 2-5 остаются без изменений.

Прочитать `docs/Готовые решения и подходы (обзор 18.10).md`. Herald `/speak` пользуется Interview Coach: сервер не ломать и не останавливать, пока Interview Coach работает. Новые модели - в отдельной ветке и отдельном процессе.

## Почему меняем подход

RUAccent ставит ударения почти верно; проблема в том, что F5 часто не выполняет «+». Приёмы вроде двойной отметки, «о→а» и повторов этого не лечат - 3.8 это показала на «отмели».

В октябре 2026 вышла модель **Qwen3-TTS 1.7B ru-stress-cf** (siriusfreak, Apache-2.0), дообученная выполнять знак ударения: 96 % против 17 % у базовой модели. Схема становится простой: ударения ставит RUAccent, модель их произносит.

## 1. Прототип

1. Подключить через **mlx-audio** (MIT, 0.5.9): единый рантайм для Qwen3-TTS, Chatterbox, VoxCPM2. F5 остаётся отдельным бэкендом.
2. Сконвертировать ru-stress-cf в MLX (8 и 4 бита). Если конвертация не идёт - зафиксировать причину и попробовать GGUF-сборку (sknyazev/qwen3-tts-12hz-1.7b-ru-stress-gguf) или запуск через PyTorch/MPS.
3. Ударения:
   - RUAccent turbo3.1;
   - слова с заглавной буквы перед RUAccent переводить в нижний регистр (по карточке модели точность растёт с 95.2 % до 97.4 %);
   - «+» переводить в U+0301 после ударной гласной.
4. Клонирование: голоса Герасимова и Ященко по тем же образцам, что у F5.
5. Замер на M4: скорость (во сколько раз быстрее реального времени), память, время первого звука.

## 2. Слепое сравнение для Андрея

1. Набор 20 фраз:
   - все упрямые слова из задания 10 («о́тмель», «ка́торжник», «ча́ек», «долги́», «по́черком»);
   - омографы («за́мок / замо́к», «се́ла / села́»);
   - редкие слова;
   - 3 длинных абзаца.
2. Движки (буквы вместо имён):
   - Qwen ru-stress;
   - F5 Misha (текущий);
   - Chatterbox Multilingual V3;
   - VoxCPM2 (48 кГц - проверить металлический звук).
3. Два отдельных набора:
   - **только ударения**;
   - **только качество звука** (металл, естественность) - Андрей в прошлый раз оценивал только ударения, звук не сравнивался.
4. Решение о движке по умолчанию - за Андреем.

## 3. Автоконтроль ударений без словарей

2. Проверка готового аудио: детектор ударения по звуку (meter2 из репозитория siriusfreak, `meter/`; лицензию проверить). Фраза с ошибкой пересинтезируется автоматически, не больше двух раз.
