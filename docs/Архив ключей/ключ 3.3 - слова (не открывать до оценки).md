# Ключ: Сравнение 3.3 - слова (диалог) - НЕ ОТКРЫВАТЬ ДО ОЦЕНКИ

| буква | что |
|---|---|
| Е | 3.3: куски 187, проверка слов по звуку |
| С | 3.2: куски 280, без проверки слов |

Те же фразы «слова», что в 3.1 и 3.2 (диалог), основной движок, 12 шагов, голос Вячеслава Герасимова, одно и то же зерно. Один вариант - как 3.2 (куски по 280 знаков, без проверки слов), другой - 3.3 (куски по 187 знаков, проверка слов по звуку с пересинтезом).
