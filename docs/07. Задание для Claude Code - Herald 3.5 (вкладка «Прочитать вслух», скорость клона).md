## 1. Скорость клона - главное

Цель: **RTF клона ≤ 1,0 на M4** при том же качестве (слепое сравнение). Тогда поток стартует через одну фразу при любой длине текста.

Сначала замер, где уходит время (по куску: подготовка образца, проход модели, вокодер, проверка слов, пересинтезы, ffmpeg), на «Пример - проба пера.txt». Потом проверить по очереди, каждый вариант - отдельный замер RTF и, если меняется звук, слепая пара:

1. **Образец голоса пересчитывается на каждом куске** (приёмка 3.4: «не меньше 6 с на вызов»). Всё, что от образца можно посчитать один раз (мел-спектр, текст образца, кодировки), - кэшировать на всё время работы. Стоимость прохода растёт с длиной образца: проверить укороченный образец (6-8 с вместо нынешнего) - только со слепой парой.
2. **Пакетный синтез:** несколько кусков за один проход модели (MLX, batch). На видеоядре это обычно даёт заметный прирост пропускной способности.
3. **Конвейер вместо очереди:** проверка слов по звуку (CPU) для куска N идёт параллельно с синтезом куска N+1 (GPU); пересинтез - только по флагу.
4. Длина куска: 187 знаков (3.3) дала больше накладных на образец. Переизмерить 187 / 250 / 320 с текущей проверкой слов.
5. Оптимизации без смены модели: `mx.compile`, fp16 / bf16 там, где это не меняет звук (сравнить побитово или слепой парой).

В отчёте - таблица: вариант → RTF → качество (слепая пара, если звук меняется) → решение. Взять всё, что ускоряет без потери качества.

**Прогноз времени** должен совпадать с фактом в пределах 10 % (было 3:01 против 3:22) - учитывать проверку слов и пересинтезы по накопленной статистике.

## 2. Старт потока: выбор «сразу» или «без пауз»

Пока RTF > 1, есть только два честных варианта - пусть человек выберет:
- **«Начинать сразу»** - первый звук после первой фразы (≈ 10 с для клона), если следующий кусок не готов - пауза на границе предложения. По умолчанию для вкладки «Прочитать вслух».
- **«Без пауз»** - старт по расчёту, как сейчас. По умолчанию для пробника.

Показ: «Звук через ~N с» и, для «сразу», «возможны паузы».

## 3. Отдельная вкладка «Прочитать вслух»

Вынести из главной в **отдельную вкладку в левом меню** (с иконкой, рядом с «Озвучка», «Голоса», «Настройки»):
- **Большое поле текста** на всю высоту вкладки, с прокруткой; шрифт как в окне, масштаб «A− 100% A+» действует.
- **Cmd+A / C / V / X / Z** (Ctrl на Windows и Linux) и контекстное меню «Вырезать / Копировать / Вставить / Выделить всё». Проверить **с русской раскладкой**: в Tk на Mac сочетания с Cmd по умолчанию не срабатывают при русской раскладке - привязывать по коду клавиши, не по символу.
- Кнопки: «Из буфера», «Открыть файл» (txt, docx, fb2, epub, pdf - тем же чтением, что для книг), «Очистить».
- **Выбор голоса в два шага:** «Быстрый» / «Клон» и рядом выпадающий список конкретного голоса:
  - Быстрый - голоса Silero (ru: Айдар, Евгений, Байя, Ксения, Ксения 2; en - если есть в модели);
  - Клон - все голоса со страницы «Голоса» (Вячеслав Герасимов и остальные, с их эффектами).
  Выбор запоминается.
- «Начинать сразу / Без пауз» (п. 2), «▶ / ❚❚ / ■», «Сохранить» (mp3), счётчик знаков и прогноз длины звука и времени ожидания.
- Пока играет - подсветка текущего предложения в поле (по готовым кускам), щелчок по предложению - начать с него.

### 3а. Ползунки голоса справа (пожелание Андрея 16.10)

Справа во вкладке - панель «Голос» с теми же ползунками, что в «Голосах»: **темп, высота, басы, яркость** + «Сбросить» и «Сохранить для этого голоса».
- Работают и для быстрого голоса, и для клона. Значения по умолчанию - сохранённые эффекты выбранного голоса; изменения во вкладке без «Сохранить» действуют только здесь.
- **Время:** высота, басы и яркость - фильтры ffmpeg после синтеза, на скорость не влияют (замерить: добавка на кусок должна быть в пределах миллисекунд). Темп у клона передаётся в модель (`speed`): медленнее - больше звука, поэтому общий счёт растёт пропорционально длине звука, а RTF не меняется; у Silero - через параметр скорости модели или `atempo`. Показывать пересчитанный прогноз сразу при движении ползунка.
- Изменение ползунка во время чтения: высота / басы / яркость - применяются к следующим кускам сразу; темп - со следующего ещё не посчитанного куска (уже готовые не пересчитывать).
- Замер в приёмке: время до первого звука и RTF при темпе 0,8 / 1,0 / 1,2 для обоих видов голоса; добавка от фильтров.

## 4. Предупреждения и «Подробности»

- Предупреждения библиотек (`SyntaxWarning`, `DeprecationWarning`, `UserWarning` и т. п.) - в файл журнала, **не в окно**. При загрузке пакета Silero - `warnings.catch_warnings()` вокруг загрузки.
- «Подробности» на главной **по умолчанию скрыть.** Ссылка «Подробности» появляется только при ошибке или если включено в Настройках («Показывать технический журнал»). Журнал по-прежнему пишется в файл - «Открыть журнал» в Настройках.
